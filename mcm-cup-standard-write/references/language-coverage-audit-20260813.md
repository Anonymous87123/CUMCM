# 语言模式覆盖审计（2026-08-14 清洗修订）

## 覆盖结论

- 语料范围：2020--2025 年 A/B/C 题编号论文 59 篇、2892 页。
- 题型分布：A/B/C 为 20/19/20。
- 2892 页页级文本已重建为 8293 个正文段落；7679 个非低质量段落进入语言统计，2871 个段落标为高质量；继续排除短片段、关键词、步骤块、未完整收束、异常拉丁串和已知 OCR 错词后，1632 个进入默认全文检索。A/B/C 分别为 432/543/657 个。448 个关键正文页完成 220 DPI 复识，其中 362 页通过双门比较采用，86 页保留原文本。
- 每篇均有唯一 `STYLE-01`、论文卡、原页范围、判断轨迹、拒绝的空写法和可检索动作。
- 59/59 篇均可由 `query_style_patterns.py` 返回至少三条非空语言注记；审计同时检查触发依据、真实动作、证据行和内容下限，不以“字段存在”代替语言模式完整。
- `query_style_patterns.py --source fulltext` 可按题型、章节、模型和公开动作返回正文原段及相邻段，默认排除关键词行、低质量 OCR 和过短片段。
- 早期 15 篇补录材料已补齐“词语功能、节奏与接口、停止位置”，覆盖为 15/15。

## 可重复门禁

```powershell
python scripts/audit_style_corpus.py
python scripts/test_style_forward.py
python scripts/audit_manuscript.py <main.tex> --problem-type A --format text
```

`audit_style_corpus.py` 同时核对 59 条压缩索引、59 张论文卡、全文段落与统计文件的一致性、
全文质量分层、关键词与水印排除、A/B/C 及关键章节的低噪声检索下限、448 页复识采用关系、模型首次出现路径、59 篇全文审读和 2892 页总数。

`test_style_forward.py` 先用 12 个论文卡场景和 6 个全文上下文场景检索锚点，再审计三份非语料原句的
A/B/C 新样稿。全文场景必须返回同题型、完整低噪声、含所请求公开动作且带相邻上下文的正文；另读取 `forward-writing-calibration.md` 的三个陌生题案例，要求局部事实先于方法、段落节奏有差异，且与全文语料不存在连续 20 个汉字的照搬。三份好例不得触发模型空降或机械推理链；“一句话空降算法”和
“基线--不足--候选--选择”标题台账两个反例必须分别被拦截。

## 完成边界

本审计只负责发现语料管线断裂，真正的写作能力来自全文段落记忆、相邻上下文检索和逐章调用协议。它不证明模型正确，
不等于 OCR 能可靠还原公式或小字号表格，也不代表教师、检测器或外部文风服务对未来任意稿件放行。正式论文仍需以真实题面、代码和结果为依据，并由队员逐段
复述“为何在这里、依据是什么、结论到哪里为止”。
