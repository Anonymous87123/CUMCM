# A/B/C 题型写作与选型

## 目录

1. 共同判断
2. A 类机理与连续问题
3. B 类综合优化问题
4. C 类数据决策问题
5. 混合题处理

## 1. 共同判断

先按主导难点分类，不按题号先入为主。若核心工作是解释连续过程与几何/物理关系，按 A 写；若核心是可行决策和多约束权衡，按 B 写；若核心是从数据估计、预测、评价并支持决策，按 C 写。

## 2. A 类机理与连续问题

链式运动题可把前问图形和状态读数作为后问的证明材料：先提出首发对象或候选时间窗，再用相对变化、结构尺寸和临界图回查；不要每问重新从算法名开始。参数域优先由物理尺寸和前问已验证可行值夹定。若外层搜索含全过程最坏量，先定义该量，再按函数形态选择内层求解器；SA/PSO 的换路必须写可观察障碍。验证图分别承担约束、收敛、空间状态和跨参数趋势；前问验证发现的局部异常可以成为后问选域接口。齐次关系先证明整体倍率，粗扫确认单峰区间后才使用三分搜索。该增量来自 `EV-20260731-A242-STYLE-01`，不外推为全部 A 题共同结构。

模型链：坐标与对象定义 -> 机理假设 -> 守恒/几何/动力学方程 -> 初边值条件 -> 无量纲或参数化 -> 数值离散 -> 收敛与误差 -> 参数反演或优化。

适用方法包括 ODE/PDE、刚体与运动学、传热/扩散/波动、流体与电路、RK4、有限差分、有限元、数值积分、几何求交、蒙特卡洛和连续参数优化。

几何--索网--接收类问题须区分控制输入、节点实际位移和结构约束。先由坐标、曲面、旋转/投影建立几何基线，再把固定长度、相邻节点距离变化、连接兼容、受力和平衡条件写成约束并逐项输出残差；只满足几何拟合而未通过这些检查的结果称几何候选。硬约束超限时须报告最大违约、通过率、超限位置和修复代价，不以“多数通过”替代全体可行。最小化最大偏差等嵌套极值以小例验证方向，节点/面板分组以单元测试核对内外层索引；坐标旋转再以中心、顶点和非对称点验证正负号、方向和距离不变量，特殊节点按标识检索而不固定行号。每条备选链标记提出、推导、实现、求解和验证状态。

接收性能按“入射方向--面板法向--反射方向--馈源面交点--覆盖/重叠”闭合；投影面积比只能在给出代理误差与适用边界时使用。经验修正系数记录来源、标定样本、区间和不确定性。RMS、面积权重和接收比固定样本集、分母、单位与版本；蒙特卡洛正文和代码共享样本量、重复、种子及区间，跨分问数据用不可变版本/哈希衔接。灵敏度分析预先给出稳定判据，区分固定方案复算与每点重求解，并同时检查硬约束；程序对每个扰动点都有输出不构成稳健性证据。

证据限制：当前 20 篇 A 题均已通过逐页人工精读门禁，编号为 `2020_A070`、`2020_A147`、`2020_A195`、`2020_A212`、`2021_A028`、`2021_A115`、`2021_A217`、`2022_A001`、`2022_A022`、`2022_A171`、`2023_A0127`、`2023_A0165`、`2023_A0175`、`2023_A092`、`2024_A016`、`2024_A053`、`2024_A163`、`2024_A178`、`2024_A242`、`2025_A196`。本节保留由单篇证据触发的路线及适用边界；59 篇总语料已经闭环，但不把单篇证据外推成跨 A/B/C 的共同词频。

写作时说明每一项来自哪条物理定律或几何关系；写清方向、坐标系、符号、单位、初值和边界；区分解析模型、离散格式和求解算法；报告步长/网格独立性、守恒误差、边界误差或观测残差。

选型边界：RK4 适合低维平滑 ODE，不代替 PDE 空间离散；FDM 实现直接但复杂边界较弱；FEM 适合复杂几何和变系数，但建模与实现成本更高。黑箱优化只能寻找参数，不能替代机理方程。若瞬态过程在前期尚未稳定，先由状态曲线确定统计窗口，再在稳定窗内计算目标；先粗略遍历判断峰值或可行区，再用 GA 等精细求解器定位参数。周期误差或参数扰动只能在先给判据、再给误差来源的条件下作为检验/可靠性证据。

本段新增的稳定窗口、粗搜--精求和扰动判据来自 `2022_A001` 单篇证据；其他路线仍分别保留各自来源编号和边界。20 篇 A 题虽已全部完成门禁，但本轮尚未统一计算章节、词语或篇幅统计，故不在此提前给出频率结论。

A022 补充了一个选型边界：方程前先由平衡位高确认浸没条件，然后以前问数值结果授权从复数解切换到 `trapz` 数值积分或非惯性系小角近似；图形显示单调后才固定阻尼上界并局部加密其他变量。这是单篇可迁移的“边界--授权--方法--上界”推进，不是 A 类共同频率结论。

A171 再补一条机理题接口：先由平衡压缩量和吃水写出分段浮力的适用边界，再用“常系数/速度相关”解释拉普拉斯与 RK4 的分工；功率目标取最后十个稳定周期，解析解、RK4 和垂荡--纵摇耦合结果用同一组时刻和状态量交付；误差检验把初始过渡段与稳态段分开，并将稳定段误差转成明确判定。这是“边界--方程性质--方法--同口径--判定”的单篇推进，不是 A 类共同频率结论。

A0127 补充工程光学与空间优化接口：先把三问区分为正向计算、反问题和放宽约束，再从功率依赖式中隔离大气透射、余弦、阴影遮挡、截断和反射率等效率。塔影简化按“精确边界负担--完全覆盖对象数量占优--中心对称/统计补偿--镜面中心判定”给依据；相邻镜遮挡按“A 坐标--场坐标--B 坐标--平面交点--区域内外”落成二值判断；截断按全反射能量、无效点损失和接收射线闭合。效率云图可直接触发镜面集中方向、塔址反向移动和塔位区间，硬镜间距再用特征直径连接内区密排与外区错位。变量较多时按计算预算使用二分或大步长定位、小步长精化，并以同一效率组比较布局策略；灵敏度需同时报告扰动范围、方向非对称、饱和位置和分效率排序。该路线来自 `EV-20260730-A0127-01`，不把有限枚举写成连续全局最优。

A0165 补充了另一条定日镜场计算路线：先把矩形点判定等价为两个三角形判定，再由太阳位置、入射/反射方向和镜面法向建立传播几何；遮挡只检查六个近邻，以射线--镜面平面交点和区域内外完成栅格判定，截断则用锥形光斑与接收区域相交。全年代表时刻计算后，用空间效率散点图确定塔向南移动的方向变量；在保持其他变量不变时分别研究塔距 $D$、镜面宽高 $W=H$ 和环距关系 $d_r=W+5$，由单峰响应对 $D$ 与 $W$ 作三分搜索。问题三继承第二问的 $W$、$D$ 与镜面位置，只开放各圈安装高度并用蒙特卡洛搜索；检验通过改变 8:00--10:00 的采样时刻，比较峰值移动是否符合太阳视运动。$2\times2$ 快速栅格只在同输入下报告不足 $2\%$ 的分辨率偏差，不能写成独立灵敏度；三分搜索和高度蒙特卡洛也不构成全局最优证明。该路线来自 `EV-20260730-A0165-01` 与 `EV-20260730-A0165-STYLE-01`。

A0175 补充“程序分支--邻接候选--抽样预算--结果后再判断”的路线。入射光线先判塔影，成立时停止邻镜与接收计算；未成立才依次判入射阴影、反射遮挡和集热器接收。全场两两比较先写出对象数、镜面网格和锥束角度共同形成的计算量，再以阴影遮挡的邻近性建立 20 m 距离邻接矩阵。问题二先用圆环蜂窝点阵和整体旋转压缩逐镜位置变量，再以 10% 镜面重复 10 次估计粗参数；旋转角和高度试算后影响较小，遂冻结并继续遍历镜宽与塔坐标，最后以 30% 镜面重复 5 次汇总。步长序列只支持“1.5 m 后增幅趋缓、结果接近稳定”，不写严格收敛。方案超过 60 MW 后，作者进一步讨论删除高遮挡镜面对总功率、总面积和单位面积输出的连锁作用；第三问继承第二问布场并抬高外圈/北侧镜面。该路线来自 `EV-20260730-A0175-01` 与 `EV-20260730-A0175-STYLE-01`；抽样遍历不构成连续全局最优证明。

A092 补充“直接量剥离--遮挡并集--空间猜想复核--方向裁剪--跨问按圈降维”的路线。题面数据代入既有光学模型后，先列可直接求得的效率分量，只把受随机入射方向和镜面点影响的截断效率交给 10,000 次蒙特卡洛。入射遮挡区与反射遮挡区可能重叠时，不直接相加，而将镜面离散并统计两区域并集。环序号曲线先提出北侧高值猜想，再以春分日上午 10 时二维图复核；固定其余参数沿东西、南北扰动塔位后，由东西方向近似对称且上午/下午影响抵消，冻结横向坐标。问题二变量仍高维，采用聚合参数粗遍历和 GA 镜位搜索；问题三沿用同心圆布局，由各向同性令同圈共享尺寸/高度，把逐镜变量压为逐圈变量，再切换到变步长遍历。100 组同约束随机可行解只给有限样本背景，不证明全局最优。该路线来自 `EV-20260730-A092-01` 与 `EV-20260730-A092-STYLE-01`。

A016 补充“局部递推--物理选根--首次事件缩域--回退求精--固定量证明--跨区复用--齐次缩放”的路线。先以等距螺线弧长确定龙头状态，再由相邻把手定长关系向后递推；多根须同时满足构件排列顺序和局部小角度。首次碰撞由下游轨迹继承缩至龙头/第二板凳与少量目标顶点，矩形投影首次触发即停。终止时刻和最小螺距分别使用内层时间搜索与外层参数搜索，均保留越界回退、缩步和误差上界。调头两圆弧在题设相切与比例约束下总长度固定，先证明不可继续缩短，再建立四区域状态矩阵；跨区逐项修改角度方向、坐标符号、切向量和边界。速度递推的齐次性允许由已有速度矩阵和上限整体缩放。该路线来自 `EV-20260731-A016-01` 与 `EV-20260731-A016-STYLE-01`，不外推到任意曲线族。

A196 补充“逻辑状态可积化--结构证明授权算法--凸性缩减采样域--理论误差与输出复算双裁决--算法共同结构物理解读--理想起点与完整模型接管--可解释任务收益分层”的路线。遮挡先写成任意圆柱点视线与球体相交的布尔值，再积分求总时长；连续且不往复的相对运动证明有效时刻只有一次进入和退出，随后才二分边界。圆柱表面通过导弹视角外轮廓、平面截面圆盘和凸性缩到上下圆周，点数同时由内接多边形面积误差和最终时长平台选择。多起点搜索与 PSO 的对照先读共同高速/小角度/早投放结构，再由导弹--目标视线解释。多机单弹用预测拦截点重合生成近似起点，完整圆柱判定在局部网格中接管；多机多目标先用飞行时间挤占云团寿命定义分配收益，再拆三个子问题。该路线来自 `EV-20260801-A196-01` 与 `EV-20260801-A196-STYLE-01`；附件代码未印入 PDF，内部对照和有限网格不构成外部验证或连续全局最优证书。

## 3. B 类综合优化问题

模型链：决策变量 -> 目标函数 -> 硬/软约束 -> 基线精确模型 -> 求解复杂度 -> 精确或启发式算法 -> 可行性修复 -> 对照与敏感性 -> 决策建议。

适用方法包括 LP/NLP/QP、整数与混合整数规划、0-1 规划、多目标规划、随机/鲁棒规划、动态规划、图与网络流、离散事件/蒙特卡洛仿真、GA/PSO/SA/ACO/DE、NSGA-II/MOPSO。

写作时用集合、索引、变量域和单位定义决策空间；对每条约束写业务来源；区分原问题、线性化/松弛、求解器和可行解修复；同时报目标值、约束满足情况、时间和基线差异。

当 B 题同时包含实验数据分析、条件优化和追加试验时，可把主链写成“受控条件分组 -> 趋势/相关 -> 现象与机理共同选型 -> 多响应回归或方差分析 -> 目标量直接建模 -> 分结构/分约束优化 -> 有限预算试验设计”。分组必须来自数据生成过程；复杂回归须与可解释基线使用同一数据和指标；模型选型先写散点形态、过程上界和适用区间；少样本高阶拟合还要联合样本数、自由度和外推目的裁决，不能把 `R^2=1` 自动当作最佳。控制变量比较逐项写保持条件、唯一改变量、比较组和每个响应，只把结论限定在当前组与采样区间。递进回归逐层保存旧指标、剩余不足、新增结构和新指标；诊断修模保留初始模型、诊断图、具体问题、修正动作和修正模型；从回归/规划切换到神经网络等方法时说明旧方案为何不适配。回归结果分别用 R/R 方、RMSE/MAE 和 F/p 或同类统计量承担相对效果、绝对效果与整体检验。每个最优值同时报告适用条件和变量组合。补充实验有三种组织方式：若由设计理论统一生成，写次数预算、因素筛选、水平依据、安全修正和备选取舍；若由不同未决问题逐项推出，则逐组写前文缺口、保持条件、改变因素、新增观测和裁决用途；若一部分探索未知区域、一部分确认预测点，则先标记证据角色，再分别给覆盖逻辑与误差比较。每个实验还须在实施前写明“若……则……；否则……”的裁决规则。行文可使用“观察附件……发现……”“根据散点图……但由于……因此建立……”“但经数据比对……因此……”“又因为……而……因此可以推断……”“由于只有……个点，虽然……但……”“当……相同，只改变……时，将……组进行对照”和“从相对效果看……；从绝对效果看……；从方差分析方面看……”，但省略处必须是本题实体和证据。该路线来自 `EV-20260730-B007-01`、`EV-20260730-B026-01`、`EV-20260730-B050-01` 与 `EV-20260730-B160-01` 四个单篇观察。

当 B 题的难点是多种几何次序、拓扑或分支而非传统规划时，主链可改为“完整分类 -> 等价关系压缩 -> 保留分支建模 -> 扰动/位置遍历 -> 身份或状态识别 -> 基准子结构 -> 分量调整 -> 结构转化 -> 旧模型复用 -> 特殊对象处理”。分类必须先覆盖原情形，再以旋转、交换、平移或同构映射给出压缩依据；不能只说“为简化模型”。遍历写清固定量、循环对象、范围、步长、记录项和输出。复用前问模型先核对输入、输出、目标与几何/状态条件；结构转化后的异常点单独处理。若结果规模过大，正文说明完整文件位置和代表样本依据，再按“读数--机制--有限误差--整体参照”解释。该路线来自 `EV-20260730-B030-01` 单篇观察。

若几何定位还能利用定弦定角、对称交点等不变量，应先把区域方程的分类负担写出来，再转成轨迹交点；圆心、交点和候选侧别分别用旋转矩阵、叉积或对称关系落地。带误差的身份判定不宜只报蒙特卡洛准确率，可按“具体误差例 -> 候选短弧/区域 -> 端点检查 -> 角度变化界 -> 区间穷举”给出确定性边界。队形调整可用 $L_2$ 等整体指标比较贪心和前视搜索，但须区分局部一步优势与终局目标，并公开前视深度、执行第一动作的规则和重置方式。停止轮数由任务精度与通信/调整代价共同裁决；复用模型前先审计共线、共圆等退化。该路线来自 `EV-20260730-B035-01` 单篇观察。

若题目同时规定信息不共享和编队整体评价，主链可写为“解析定位与解唯一化 -> 角集合判号 -> 预处理误差界 -> 局部可观测目标 -> 事后全局评价 -> 双方案同数据比较 -> 几何引理装配 -> 三维/平面检验 -> 随机扰动”。可见信息、禁用信息、局部目标和全局评价必须分栏；预处理同时报告误差界与搜索/信号收益；方案按收敛速度、稳定误差和资源代理裁决，并说明代理不是现实调整次数。每条几何引理映射到固定点、调整点、控制角或比例及具体机群；单组初值不足时用明示分布的多组扰动补证。该路线来自 `EV-20260730-B086-01` 单篇观察。

覆盖几何--测线规划--局部地形拟合类 B 题可按“二维覆盖几何 -> 两个缺失量 -> 命名平面/法向/交线 -> 方向证明 -> 边界锚定贪心 -> SA 同指标比较 -> 等深线初分 -> 局部平面 -> MSE 触发再分区 -> PSO 参数 -> 分区贪心 -> 总长/漏测/过度重叠核算”组织。复用二维模型前先点出水深和测线--坡面夹角这两个接口；规程提供方向动机，等长候选的覆盖面积比较给出数学依据。贪心须写东/西等起始边界、首线恰达规则、步长、可行区间、取最低可行值和终止边界。分区拟合先公开人工等深线依据，再由 MSE 只拆失败区；结果按区域分别解释坡度、覆盖宽度、线数和漏测。该路线来自 `EV-20260731-B226-01` 与 `EV-20260731-B226-STYLE-01`，不把 PSO、SA 或贪心名称本身写成创新。

同类覆盖题若题面术语存在竞争定义，可按“两个定义 -> 同一数值例 -> 可区分的 CAD/实测量 -> 裁决 -> 任意方位推广 -> 小坡度长尺度累积 -> 方向选择 -> 规范印证 -> 边界递推闭合 -> 最不利位置全域规则”组织。推广前列不变结构和改变量，只替换受影响的覆盖函数输入；参数能否忽略由完整测区累计量和两端可行区间决定。检验分别核对对称性、单调性、沿等深线方向不变和极限式。递推必须报告最后可行测线、对边余量和下一候选的处置。该路线来自 `EV-20260731-B311-01` 与 `EV-20260731-B311-STYLE-01`，不把单篇定义或方向写成全部覆盖题的固定结论。

当覆盖定义在斜坡情形出现可观察的反直觉排序、真实地形又是离散数据时，可按“共同量反例 -> 投影量修正 -> 二维关系 -> 航向固定下的坡度唯一性 -> 三维输入替换 -> 最大覆宽方向 -> 边界递推与参数区间 -> 离散方案负担 -> 学习模型输出接口 -> 多起始线搜索 -> 公开失败状态 -> 等深线分区 -> 局部修复 -> 主文/附件结果分流”组织。定义修正只动造成矛盾的量；学习模块必须交付任意点的深度、梯度、坡度和覆宽；分区由起点依赖或漏测等实际失败触发，只处理失败区域。多起始线只能支持已比较候选中的代表，连续航线与返航须另接图网络模型。该路线来自 `EV-20260731-B477-01` 与 `EV-20260731-B477-STYLE-01`。

生产抽检--检测--拆解类 B 题可按“业务态度分流 -> 相反假设 -> 功效/成本权衡 -> 完整二元决策空间 -> 循环终止规则 -> 简单分支统一式/复杂分支代表推导 -> 全量方案表 -> 规模审计 -> 状态--决策模型 -> 参数不确定性接口替换 -> 策略与数值双重对照 -> 先验局部扫描”组织。业务态度若改变拒收/接收方向，不能只换显著性水平；代表方案须按互斥事件给条件、概率、后续操作和成本，并说明未展开公式的去向。模型切换由组合数量、工序数或零件数的实际增长触发。后问若沿用旧决策集，只把目标写成次品率函数并对后验积分；结果段明确多少情形策略不变、哪一情形切换和原方案差距。该路线来自 `EV-20260731-B159-01` 与 `EV-20260731-B159-STYLE-01`，不把 Beta、动态规划或代表编号外推为同类题固定答案。

同类题若以连续检测率和循环仿真组织，可按“无样本缺口 -> 明示仿真生成器 -> 同口径抽样比较 -> `(n,c)` 可行集 -> 分阶段数量/概率/成本会计 -> 拆后件与余量跨轮传递 -> 饱和停止 -> 理论处理与仿真实现分流 -> 连续比例求解 -> 端点化解释 -> 扩展流程的重复步骤诊断 -> 变量接口压缩 -> 利润/收敛双指标方案 -> 后验端点扰动重跑”组织。每轮必须交付下一轮初值；停止阈值要解释利润与继续循环成本；删除步骤要点名重复的状态转换；变量压缩要给原数量、等价或互斥条件和保留数量。两个方案不因利润有高低就强行只留一个，若收敛速度改变实际时间偏好，应分别说明短期与长期用途。该路线来自 `EV-20260731-B195-01` 与 `EV-20260731-B195-STYLE-01`，不把正态模拟、线性模拟退火、阈值 `1.001` 或 16 位编码外推为固定模板。

同类题若按离散路径与随机搜索组织，可按“节点/反馈环计数 -> 决策树表示边界 -> 成本来源清单 -> 路径利润 -> 小规模随机候选/ACO -> 前十热点 -> 执行表与同规模利润 -> 大规模节点增长 -> 保留会计接口并替换搜索层 -> 16 位 GA/精英 -> 运行协议与收敛图 -> `mu±3sigma` 情景 -> 变化节点 -> 成本机制”组织。算法切换前必须给 4/16 等真实节点数、2/5 等反馈环数或等价规模；流程图画不下的退换环须在文字中补足。六类/九类成本不只是清单，每项须交代触发条件和计数口径。鲁棒性先定位改变的节点，再找共同的成本或损失属性。该路线来自 `EV-20260731-B196-01` 与 `EV-20260731-B196-STYLE-01`，不把 ACO、GA、精英数、`3sigma` 或主导热点外推为固定答案。

材料测量、光谱反演或其他“机理模型--数据提取--参数反演--模型复杂度裁决”类 B 题，可按“材料/介质机理 -> 可观测曲线 -> 局部特征显式估计 -> 全曲线参数反演 -> 两路线角色对照 -> 高阶效应无量纲判据 -> 物理因子逐项估计 -> 中间误差上界 -> 修正数据回代最终任务 -> 误差传播解释可疑点 -> 物理/优化/统计代码接口”组织。预处理必须同时写被压低的噪声、被保留的结构和交付给下游的量；局部法与全曲线法分别报告读取范围、变量和不确定度。判据中的每个因子先译成界面反射、吸收、相干或角度条件，再代入当前数据。代理曲线差小不能直接推出厚度等任务量差小，须用修正后输入重跑主算法。筛值同时给统计规则、误差传播敏感项和图上物理位置。该路线来自 `EV-20260801-B060-01` 与 `EV-20260801-B060-STYLE-01`，不把 SiC、Airy、`G`、当前阈值或高斯--牛顿外推为所有光谱题的固定答案。

当同类光谱反演同时含多角度、多数据组和局部色散失配时，可进一步按“坏频段伤害链 -> 多条件自动选带 -> 频域初值 -> 独立拟合缺陷 -> 共享物理量/独立校准量 -> 内层闭式消元/外层非线性更新 -> 残差系统结构 -> 连续约束分段 -> 主参数与局部残差双报告 -> 各职责检验 -> 多光束物理条件与数据证据”组织。联合不是简单合并样本：共享量承担物理一致性，独立量吸收仪器/角度偏差。分段修正必须由残差位置触发，并说明它改变的是主结论还是局部拟合。该路线来自 `EV-20260801-B157-01` 与 `EV-20260801-B157-STYLE-01`，不把当前频段、分点、色散式或材料结论外推为固定答案。

资源--路径--不确定性--多人交互的复合 B 题，宜先按信息结构列出四列：可见信息、状态、动作、目标。共享库存/现金转移后，确定性层报告可行域覆盖和精确基线；随机层把知道完整未来的离线全知上界与只用当时信息的在线策略分开，并报告情景生成、缺货风险和相对上界的遗憾；多人层报告效用类型、候选空间、联合状态与阶段耦合。终点残值不能被无证明的“库存恰好为零”替代，候选路线或单日局部均衡也不能自动外推到完整路径空间和多阶段全局策略。

选型边界：可表达为中小规模 LP/MILP 时优先精确求解器；启发式算法适合非凸、黑箱或组合爆炸，但必须报告编码、初始化、惩罚、终止和多次运行稳定性。多目标问题不应只用未经解释的加权和；可给 Pareto 前沿及偏好选择规则。

随机规划与蒙特卡洛的边界：期望值决策适合先做可解释基线，但库存耗尽或灾害尾部重要时，应使用场景树、滚动优化、机会/鲁棒约束或 CVaR，并对校准后的生成器多次独立评估。`N` 个时序观测只产生 `N-1` 次相邻转移，须核对计数总数、状态顺序、计数矩阵和转移矩阵；稳态分布描述长期占比，不等于下一日或逐日预测。期望收益必须针对一项满足非预见性的共同策略计算，不能对每个完整未来情景分别求全知最优后再取 `max(P_W C_W)`；期望库存也不能代替逐路径可行性，应另报缺货概率或机会/鲁棒约束。单条随机路径只能作算例；筛选样本后须重申整数计数、条件事件和分母。博弈模型的边界：共同收益、一般和、零和与拥塞结构的支付和解概念不同；应依次核对最佳反应、支配关系、纯均衡、内点混合解和边界解，负的“概率解”只排除内点混合均衡，不能排除纯均衡；严格支配须对对手每个动作逐项比较，不能用全局或列最大值替代；混合策略不能未经新准则直接压成确定路线。

状态与实现边界：称为 MDP 的状态必须足以决定给定动作下的回报和下一状态分布；位置之外若库存、现金、日期、当天天气或他人位置仍影响决策，就必须进入状态或被证明可由当前状态恢复。正文计算的概率、稳态或参数要由实际生成器引用，不能另写常数抽样。动态规划、MDP 或博弈的强结论还须由决定性的状态递推、策略更新、支付与最佳反应/均衡求解及其输出支撑；只读取预置路径、累计后常量覆盖或列经验规则时，应按启发式算例表述。效率/公平等多目标必须用加权、词典序、约束法或 Pareto 规则闭合，并报告偏好敏感性。

证据限制：上述 B 题细则由人工精读通过的 `2020_B078`、`2020_B108`、`2020_B125`、`2020_B175`、`2021_B007`、`2021_B026`、`2021_B050`、`2021_B160`、`2022_B030`、`2022_B035`、`2022_B086`、`2023_B226`、`2023_B311`、`2023_B477`、`2024_B159`、`2024_B195`、`2024_B196`、`2025_B060` 与 `2025_B157` 共十九篇单篇案例触发，已覆盖本语料中的 19 篇 B 题。各路线是可迁移判断，不等于未经计数的共同出现率。

## 4. C 类数据决策问题

医疗筛查或其他“连续风险估计--可执行分组--分级判定”类 C 题，可按“重复测量统计关系 -> 个体阈值概率 -> 单调连续建议 -> 过早失败/过晚代价/策略复杂度 -> 分组边界与统一时点 -> 动态规划 -> 连续曲线/台阶策略对照 -> 多变量位移 -> 对照组校准 -> 稳健零分布 -> 多重检验 -> 复测一致性/质控 -> 阴性/可疑/阳性动作”组织。风险目标每项都要有现实职责；校准层与判定层不得混同；中间等级要绑定后续动作；敏感性报告时点、组数或人数如何变化。该路线来自 `EV-20260801-C023-01` 与 `EV-20260801-C023-STYLE-01`，不把当前临床阈值、分组数或分布假设外推为通用医疗规则。

同类题若同时需要个体达标时点、BMI 分组和多类异常识别，可按“记录聚合为孕妇 -> 重复测量模型 -> 个体 GPR -> 实测/保守预测/未确定三级回退 -> 风险目标 -> 分点与统一时点 -> 初诊静态分支 + 浓度序列分支 -> 右删失生存概率 -> 专项折外概率 -> 原始指标拼接 -> 元分类 -> 总体/小类两层评价”组织。特征口径由决策发生时刻限定；无趋势对象不强给时点；专项概率必须由折外预测产生；整体准确率与低频类召回、样本数同时报告。该路线来自 `EV-20260801-C132-01` 与 `EV-20260801-C132-STYLE-01`，不把当前网络结构、BMI 分点或临床阈值外推为固定规则。

模型链：数据字典 -> 缺失字段语义与候选参考质量分流 -> 近似零值/异常/重复处理 -> 成分闭合或尺度变换 -> 检验适用前提与方法分流 -> 业务潜变量与可观测代理 -> 业务后果的对称/非对称条件 -> 指标方向/归一化/权重 -> 规则筛样、探索分布与有据取舍 -> 特征与标签逐行溯源 -> 冻结外层测试 -> 可解释基线规则 -> 内层预处理/选参/多变量复核 -> 最终训练与独立测试 -> 指标门控、校准与解释 -> 有/无标签身份判定 -> 变量聚类/代表量与样本聚类 -> 候选范围证据 -> 概率或状态接口 -> 初值与时间依赖 -> 准入/额度/逐期状态联动 -> 动态权重/窗口或情景分析 -> 单期求解与跨期聚合 -> 决策与同口径效果评价。

适用方法包括相关分析、插值、聚类、PCA/t-SNE/UMAP、AHP/熵权/CRITIC/TOPSIS/VIKOR、回归分类、树模型、SVM、时序模型、交叉验证、误差和不确定性分析。

写作时先写数据口径、样本单位和时间范围；每个清洗规则报告触发数量和去留影响；区分探索性关系与因果结论；避免用全量数据拟合预处理器造成泄漏；使用与任务损失一致的指标并解释误判代价。

数据进入决策时增加两张接口表。第一张追踪原始字段、缺失处理、聚合时间窗、特征、标签和训练/验证/测试实体，防止相邻年份补全、全量选特征或同一企业跨集合造成泄漏。第二张追踪预测概率、决策变量、单位、上下界、预算残差和风险/收益项；若先预测评级再预测风险，不把中间硬标签当无误差真值，而用类别概率、联合模型或情景抽样传播不确定性。

当“稳定性、连续性、能力”等业务概念不能直接观测时，先列代理指标及各自覆盖的含义，再说明成本/效益方向、时间窗、归一化和权重；综合得分只在这些代理的口径下解释。历史均值并非默认能力指标：若它既抹平同一周期位置的变化，又与生产过程的周期性冲突，应改用相同周次、滚动窗口或条件分组，并把两个理由分别写明。

动态数据决策还要闭合状态和模块接口。逐期写出期初状态、决策、随机实现量、消耗和期末状态，后者必须进入下一期；评价筛选、逐期订购和转运分配可以使用不同方法，分别报告决策变量与输出，不用“遗传算法优化全过程”概括。结果先用全周期表图判断整体可行，再选代表时点解释状态与约束；发现预期偏好没有出现时，先诊断成本尺度、等价关系或活跃约束，再作局部修正。改善较小时同时报告最大值和平均值，并解释资源贴边或可行域狭窄。跨问复用模块须核对输入、输出、目标和约束，只对实际变化部分重建。

当统一权重只保证总体表现、却让个别时段形成严重缺口时，动态权重必须把该失败状态写在更新公式之前，并说明当前缺口如何归一化为下一轮权重。库存前视或后视范围须由连续淡季、峰谷或业务延迟确定；不能只写“考虑周期性取两周”。多种求解方法串联时按角色说明：超容量大项先拆，主体背包/规划处理可装载对象，残项再由可行规则补救；若上下层目标由分阶段程序实现，分别写阶段目标和中间接口，不冒充单一耦合求解器。二分答案要定义候选值可行当且仅当哪一个总缺口或硬约束指标为零。

方案比较先核对产出规模。历史总成本较低而历史产能未达题定基准时，总量没有直接可比性；应改用成本/产能、单位收益或其他同分母指标，并同时报告两边数值。图形解释也应点名具体旺季/淡季或峰谷时点，再落到补货、调度或风险动作。

业务损失有方向性时，不要直接套对称距离。先比较短缺与超供、误拒与误放等后果，列出零点两侧的符号、单调性、增长速度或阈值条件，再构造分段损失并说明正向化。探索图中出现周期或分组并不强制纳模；若尖峰会破坏识别、样本不足以区分周期，或新决策已经改变历史生成机制，应明确舍弃理由及仍保留的统计信息。

动态供应链还要先裁决初值和可分性。已有运行历史时，库存等状态优先取同周期同位置的历史量，不习惯性设为零；无记忆损耗可以逐周拆分，库存或恢复约束仍保留跨周接口。候选范围由尾部单体量级、头部累计覆盖率和扩围管理/采购/计算代价共同决定。局部模型若给每周最少对象数，统一方案取各周最少数的最大值；若给每周最大可行能力，全周期保证取各周最大值的最小值。结果检查区分总量关系、目标方向、单周可行性和独立预测证据。

成分数据不能把空白统一当作普通缺失。先根据题面判断未检出、未知或未采样：未检出可按题意置零；相同已知条件仍多值且表面/局部取样不能代表整体时，拒绝猜测性填补，并只在涉及该字段的分析中忽略具体样本。组成比例在回归或距离计算前先闭合并选择合适的对数比变换，逆变换后重新检查总和。统计检验先由期望计数、独立性等前提选择 Pearson、Yates 或替代方法；前问趋势可以给后问聚类赋义，但聚类结果还要反向核对前问。

指标用于决定后续计算时，逐对象保存实际指标和分支：高 $R^2$ 或高可信对象进入预测，低指标对象采取保持不变或基线策略，不静默删除。异常点若通过一个距离量放大预测，只在解释失真机制后对该量作单调压缩。R 型聚类先分变量、降相关并选代表量，Q 型聚类再分样本；新表已经直接提供风化等状态时，说明与旧表的采样语义差异并删去重复估计。跨类型灰色关联或距离比较固定同一参考序列，再比较各类最大、最小值和集中/离散程度。

同一缺失字段也可按匹配候选的参考质量分流：先列匹配条件、候选编号和采样口径，再选择热卡、众数或不填补。空白与报表零若分别来自检测限和舍入，均先按近似零值处理，不能直接进入对数比。主导成分遮蔽其他变量时，完整图和去除主导成分的图成对保留并结合解释。分类可先用简单树/阈值形成可读规则，再由 PLS-DA/VIP 等多变量模型复核；二者须使用清楚的训练/测试口径并说明分工。没有已知亚类标签时先判为无监督问题，聚类清晰度按类别分别陈述，图形不清时只作粗分。PLS 等潜变量维数同时看交叉验证误差和累计解释率，选择最小充分维数。比较两类相关矩阵时，先利用对称性取上三角去重；只有相同变量对一一对应时才使用配对检验。

零售、经营或其他“数据分析接优化”的 C 题，可在正式建模前设置数据侧写，但每个图必须回答一个后续决策问题：选什么相关口径、预测窗口、候选范围或约束上界。对象过多时按可复算规则选代表，并同时给全量结果位置。统计关系进入决策前要完成两次翻译：回归系数译成每 1 kg、1 元、1 天等业务单位；人工特征说明它如何从原对象和窗口构造、代理何种现象、进入哪个模型。若题目还要求补充数据，先把现有附件能量化的证据链闭合，再另列外部字段的采集方式、竞争机制和经营动作。退货量、打折频率等代理量存在多种成因时，不直接定性，而按“机制 A/机制 B--追加证据--分情形动作”组织。该路线来自 `EV-20260731-C050-01` 与 `EV-20260731-C050-STYLE-01`。

零值多、分布形态不同且需要由预测直接驱动订货的零售 C 题，可按“数据病态识别--样本重组--阈值决策矩阵--分布模型--诊断读表--业务时间尺度定阶--异常预测业务翻译--独立候选核对--预测/损耗/余货接口--利润优化”组织。正态性或分布假设不满足时，先说清原方法受影响处和转换后样本；相关矩阵可压为 T/F 接口，但必须保留阈值和下游动作。模型阶数由保鲜、交付或响应时间授权，再用信息准则和残差检查。负预测不直接删除，而是映射为余货、折价或不补货状态；频数规则只在候选层作有限核对。进入优化前逐项对齐预测量、损耗率、计划进货、前日余货、新补货、陈列下界、价格和成本。正文承担裁决与解释，附录承担完整后验、全量表和代码入口。该路线来自 `EV-20260731-C126-01` 与 `EV-20260731-C126-STYLE-01`。

开放探索接补货定价的零售 C 题，可按“未定探究方向--互补观察面--统计读数与现实机制--候选预测比较--失败后换模--价格弹性修正--品类连续优化/历史基线--单品数据能力诊断--必要时降级--评价筛选--$0/1+$连续混合变量--多目标 Pareto--模型边界到补采”组织。开放题先说明为什么选择时间、分布、关系等角度及其各自用途；候选模型使用同一输入、指标和窗口，写出当前不足后再换路。短窗缺失、无趋势或随机时不强行套复杂时序模型；简单估计须标明适用对象与日期。求解器变化由变量域、目标数和约束授权。基线预测经弹性或响应关系修正后，逐项接入收入、成本、损耗和补货约束。结果与同季、同星期或同状态历史基线比较；补采字段从现有模型不能区分的竞争、预期或收入机制中推出。该路线来自 `EV-20260731-C228-01` 与 `EV-20260731-C228-STYLE-01`。

农业种植或同类“数据侧写接风险优化”的 C 题，可按“资源/产量/亩均利润侧写 -> 连续面积与 0/1 选择 -> 现实规则逐项约束 -> 同目标参数化情境 -> 可执行随机搜索 -> 四类不确定量年度更新 -> 情景生成 -> VaR/CVaR -> 风险收益让渡 -> 小样本与分布前提检验 -> Spearman -> 替代/互补候选 -> 关系转面积/比例约束 -> 经济变量相关递推 -> 联合不利 -> 单项扰动”组织。图后点名对象、读数和下游接口；固定、随机、相关三层模型列明冻结项与新增项。相关图只发现候选，不等于因果；必须把方向翻译成决策变量和约束。风险段同时报告情景预算、置信水平、尾部比例及收益代价。检验区分所有风险同时不利与一次只改一个参数，并说明固定策略复算还是重新优化。该路线来自 `EV-20260731-C038-01` 与 `EV-20260731-C038-STYLE-01`。

检验至少区分交叉验证选参、最终训练集拟合和独立测试评估。监督标签逐行保存来源字段、生成规则、实体索引和类计数；不得按行号切片制造正负类。模型名、损失与拟合 API 必须同源，Logistic 分类不能以普通最小二乘 `regress` 代替二项似然而不改名和说明。训练数据上的 Accuracy/AUC 只能称回代指标；训练、验证和测试实体集合须显式去重并报告交集为零。外层测试集不能参与缩放器/校准器拟合、特征选择、阈值确定或集成权重学习；每个估计器首次 `predict` 前须有 `fit` 或模型载入证据，构造参数名须由所用库版本识别。挑战模型必须在同一划分、同一指标和同一计算预算下比较。分类任务除准确率外，根据类别不平衡和误判成本报告混淆矩阵、召回率、PR-AUC、概率校准或成本指标；AUC 应读取连续分数/概率，不以硬标签代替。投票或堆叠权重须在内层验证中学习，并在冻结外层测试上只评估一次。有序分类不能只把等级编码为连续数后报告相关系数；须说明输出层与损失、等级切分阈值、越界输出处理，并报告逐类召回、宏平均或加权成本。规划层的离散变量不得为了适配连续求解器而无说明删除；可选对象以 $z_i$ 和 $x_i$ 联动，不能用 $x_i\ge L>0$ 强制全选后又输出零值。政策折扣、取整和阈值恢复必须进入求解或接受完整的可行性修复与约束复核。正文目标、执行代码、对象规模、结果表和复算日志必须同源。随机优化的“最优目标”和最终策略必须来自同一候选解，并用解标识或哈希贯穿排序、导出与结果表。

选型边界：PCA 保留线性方差结构，特征向量只可按整列统一换号，不可逐元素取正；得分矩阵须按“标准化样本矩阵乘所选载荷列”做维度和正交性检查。TOPSIS 必须实际计算正负理想解、到两理想解的距离和相对贴近度；仅做熵权加权和时应按实际算法命名。最近中心/均值分类须让正文距离公式与代码同式，并检查根号定义域和尺度标准化。t-SNE/UMAP 更适合可视化而非直接解释全局距离；ARIMA 适合较稳定线性时序，树模型适合非线性特征，RNN/LSTM/GRU 需要足够样本并防止时间泄漏；评价决策模型的权重应做扰动检验。风险阈值须把降序第 `k` 位换算成升序分位并核对所取尾部、并列值和业务方向。手设违约概率、风险分数和冲击矩阵时，先校验概率位于 `[0,1]`、正文公式与代码一致，再报告地区适用性、样本、时窗、标定来源、区间、归一化方式和敏感性；风险参数 `Q` 必须声明是相对增量还是总倍率，若正文用 `(1+Q)`，实现、单位表和边界样例不得直接换成 `q` 而不裁决。若写期望损失 `EL=PD\times LGD\times EAD`，逐项给单位并避免把授信金额同时吸收到 LGD 和 EAD。把某个输入指标或同一组特征反过来检验由其构成的综合指数、评级或概率，只能称内部一致性，不能称外部验证。聚类分群进入政策调整时，至少对聚类数、距离/标准化口径、风险乘数和客户流失率重求解，报告策略切换而不只展示单点结果。

农业规划也可采用 C063 的‘基期事实 -> 变量域 -> 确定性规划 -> 两轮控制变量 -> 典型状态候选 -> 统一环境交叉复算 -> 益损值矩阵 -> 现实损失态度 -> 期望/乐观/max--min -> 因素幅度与优先级 -> 替代/互补定义 -> 面积/亩产接口 -> 完整组合对照’路线。典型状态用于解释，统一环境用于公平裁决，不把二者的状态数混写；求解器由变量维数、约束和目标结构选择；风险准则先交代何种现实损失不可接受。该路线来自 `EV-20260731-C063-01` 与 `EV-20260731-C063-STYLE-01`。

同类农业规划还可采用 C094 的“地块适宜性与季次 -> 面积/选择/销量变量 -> 双销售目标 -> 管理 `p/q` -> Gurobi/状态贪心同口径比较 -> 随机候选生成 -> 统一环境交叉复评 -> 替代候选门与目标门 -> 互补关系分别修正亩产/成本 -> 冻结主体接口并增量求解”路线。管理口号必须转成参数与候选表；贪心须维护历史、剩余面积和需求；随机样本须说明用于生成还是评价；替代/互补须进入具体经济量。该路线来自 `EV-20260801-C094-01` 与 `EV-20260801-C094-STYLE-01`。

农业规划还可采用 C234 的“附件同源补全 -> 季次/地块对照决定参数索引 -> 面积变量与双销售目标 -> 十四类现实约束 -> 结构体染色体与可行生成 -> GA 预算/早熟注入/修复 -> 收敛 + 约束诱导形态 + 极端基线 -> 年度随机参数 -> 地域灾害/季节/作物损失 -> 三工况方案裁决 -> 替代/互补定义和分组 -> 供需修正 -> 冻结约束并增量求解”路线。方法创新由信息接口和可核判断支撑，不以算法名数量衡量。该路线来自 `EV-20260801-C234-01` 与 `EV-20260801-C234-STYLE-01`。

## 5. 混合题处理

将主导方法写成主链，其他方法作为接口。例如“预测需求 -> 鲁棒优化订货”仍可按 B 类组织，但数据章节须遵守 C 类训练/验证规范；“机理仿真 -> 参数优化”按 A 类解释方程，按 B 类说明目标与约束。
