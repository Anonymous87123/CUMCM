# 单次受保护学术改写

## 适用位置

只在模型、代码、结果和证据稿已经稳定后使用。它解决的是段落组织过整齐、套语过多和表述不贴近实际建模动作，不负责补模型、补试算或修改数学结论。

同一段正文只进入一个改写 Skill 的一轮处理。`humanize-academic-chinese`、`baibaiAIGC` 或其他降 AI 工具不能串联；第二轮常把第一轮留下的具体判断磨成均匀句式，并削弱“仅在当前情景”“不构成因果”等限定。

## 改写前冻结

- 数学环境及行内公式；
- 数字、正负号、百分数、单位和有效位数；
- `section/subsection/subsubsection` 标题与层级；
- `label/ref/eqref/cite`、图表编号和文件路径；
- 变量、模型、指标、数据表字段和题面专有名词；
- 摘要、正文、表格、结论及附录中的结果字面量。

另存改写前 TeX，术语较多时建立一行一个词的 `protected-terms.txt`。改写后运行：

~~~bash
python scripts/audit_rewrite_contract.py before.tex after.tex \
  --terms protected-terms.txt --format text
~~~

该门还会给明显缩短且同时移除多处条件、转折、依据或结论边界的 changed block 标记
`ARGUMENT_COMPRESSION_REVIEW`。这不是最低字数或保长规则：精简重复内容可以保留，但要逐处
确认模型职责、事实关系、限制和结果解释没有随句壳一起消失。位置、压缩率、移除线索与
`finding_sha256` 必须进入同一候选的语义裁决，不能用“更简洁”统一放行。
裁决记录必须声明 `reviewer_kind: human`；模型可以整理候选上下文和建议，但不能自行接受语义变化或把 `REVIEW` 改成 `PASS`。

## 改什么

- 删除没有承担判断的开头和收尾；
- 把判断放回触发它的图表、公式、边界、试算或结果附近；
- 保留段落长短差异，不强行为每段补齐依据、方法、结果、解释和边界；
- 只在证据存在时保留候选、失败、比较和取舍；
- 将泛泛的算法优点改为本题变量域、精度、规模或现实后果。

## 改写后的局部回修

一次候选完成后，若仍有某个段落显得机械，不再把它送入第二个降 AI 工具。先定位该段实际依赖的题面事实、数据现象、公式、试算、前问接口或结果，再只重写这一段的判断连接和推导表达；没有找到触发它的事实，就删掉无依据的扩写或收窄结论。局部回修属于内容写作，不属于第二轮人文化处理，完成后只重新运行保护项、语义和引用审计。

## 不改什么

不能为避免禁用词而更换术语、删限定、合并不同指标或重排数学逻辑。审计通过只说明受保护对象没有漂移，仍须逐段朗读并由队员复述模型。
