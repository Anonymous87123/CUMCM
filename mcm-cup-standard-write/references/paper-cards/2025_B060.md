## 实际模型链

`Lorentz--Drude/Caughey--Thomas -> SiC 复折射率 -> Snell + s/p 菲涅尔 -> 双光束反射率 -> 相邻波谷厚度式 -> 样条/极值 -> 逐对厚度 -> 3sigma 筛值 -> 均值/区间/CV/反方差合并 -> [d,logN1,logN2] 最小二乘 -> 4×4×4 网格初值 -> 有限差分雅可比 -> 高斯--牛顿 -> 双路线印证 -> Airy 多光束 -> G 显著性 -> 反射/吸收/相干/角度条件 -> 2G 阈值 -> 二阶导噪声传播 -> 硅片双路线 -> G+均方误差裁决 -> SiC 谱线修正与重算 -> 频数--厚度误差传播 -> 共振区可疑点解释 -> Python 物理/求解/统计接口`。

## 结果与检验摘录

- 周期波谷法主叙事报告 `7.544±0.170 um`，10°/15° 有效样本 11/15，CV 为 `2.802562%/3.799922%`；网格--高斯牛顿为 `7.295 um`，并给两层掺杂浓度和全曲线拟合。
- 硅片周期法为 `3.453±0.063 um`，反演为 `3.414 um`，摘要综合为 `3.432 um`。
- 附件 3/4 的 `G=0.036/0.030`，双/多光束均方误差为 `20.8/3.62`，支持显式多光束模型。
- 附件 1/2 的 `G<=0.016/0.010`；修正谱重算为 `7.5461±0.1801 um`，多光束反演约 `7.560/7.571 um`，论文最终取 `7.455 um`。
- p.27--28 由厚度对波谷频数的导数解释共振区误差放大，并把可疑点与大 `|dn/dv|` 位置对照。

## 人类文风与判断轨迹

1. 样条段明确两个用途：压高频噪声但保留周期形态；生成可求导曲线以定位波谷。
2. 极值图先给绿/红点的证据身份，再承诺在检验节用误差限解释红点，图例与后文形成接口。
3. 双路线不写成模型名清单：周期法取局部极值，反演法用整条曲线并同时估计掺杂，两者职责不同。
4. 网格--高斯牛顿保留“初值覆盖--残差--有限差分雅可比--最小二乘更新--收敛”的动作链。
5. `G` 沿界面反射、层内吸收、相干长度、偏振/角度和全反射逐项拆出物理条件，再由最坏偏差 `2G` 给阈值。
6. 明说不能只看反射谱最大差距判断厚度影响，必须把修正谱重新送入两种算法比较最终输出。
7. 删点先推频数误差如何传播到厚度，再用共振区大导数和图中红点位置解释，而非只报 `3sigma`。
8. 问题三总结用“首先--其次--再次--随后--最后”回收模型、判据、精度、数据裁决和修正，每个序词对应真实动作。
