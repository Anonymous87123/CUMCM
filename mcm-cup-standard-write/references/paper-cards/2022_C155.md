## Model chain

`valid-sum screening -> closure to 100% -> centered log-ratio transform -> semantic missing-value handling -> expected-count gate for Pearson/Yates -> four-group descriptive statistics and boxplots -> Q-clustering for weathered points -> four-stage weathering sequence -> component-wise quadratic regressions with R^2 routing -> outlier-distance compression -> inverse log-ratio and closure validation -> weathering-stratified PbO decision trees -> R-clustering of variables -> representative components -> Q-clustering of samples -> bounded random perturbation -> unknown-sample tree classification and Q-cluster cross-check -> threshold margins -> fourteen-reference-sequence grey relational analysis`

GBDT is mentioned in problem analysis but is not built or solved later. VAR and greedy search are not part of this paper's implemented chain.

## Reported results

- Surface weathering versus glass type has `p=0.009`; weathering versus color and pattern have `p=0.507` and `p=0.084` in the paper's tests.
- The unweathered decision tree uses `PbO=8.495`; the weathered tree uses `PbO=6.155`. Precision, recall, accuracy, and F1 are all reported as 1 on both the 70% training and 30% test partitions.
- `A1,A6,A7` are classified as high-potassium glass; `A2,A3,A4,A5,A8` as lead-barium glass. Q-clustering gives the same grouping.
- Representative-variable perturbation limits range from `0.05` to `0.20` without changing the reported subclasses.
- With SiO2 as reference, high-potassium glass has `P2O5=0.986` highest and `Na2O=0.893` lowest; lead-barium glass has `PbO=0.991` highest and `Al2O3=0.667` lowest. High-potassium relation values are more concentrated, while lead-barium values are more dispersed.

## Human style rules extracted

1. Turn a task threshold directly into an action: `题面范围 -> actual sample IDs -> invalid judgment -> removal`.
2. Let missing-data semantics justify not imputing: `same known conditions still yield multiple colors + surface sample cannot represent the whole object -> refuse speculative fill -> omit only from the affected analysis`.
3. Put assumptions before the statistical method: `expected-count table -> pass/fail -> Pearson/Yates branch -> conclusion`.
4. Reuse earlier results bidirectionally: an earlier trend labels a later cluster, and the later cluster is then used to cross-check the earlier trend.
5. Route computation immediately after a metric: high `R^2` components are predicted, low `R^2` components follow an unchanged branch.
6. Explain a local robustness repair as `sensitive quantity -> outlier amplification -> prediction distortion -> monotone compression`.
7. Distinguish variable clustering from sample clustering: R-type groups correlated components; representative variables then feed Q-type sample clustering.
8. When a new table has a different sampling meaning, state which preprocessing step can be removed before reusing a trained model.
9. Compare categories under one fixed reference sequence, report each category's maximum and minimum, then compare concentration versus dispersion.

## Boundaries

All values are paper-reported and raster-checked rather than independently reproduced. The 70/30 split, clustering checks, and bounded perturbations do not prove general external validity. Original-paper defects unrelated to method semantics are not expanded into the learning record.
