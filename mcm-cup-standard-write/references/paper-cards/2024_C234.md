## 实际模型链

`智慧大棚数据补全 -> 季次/地块对亩产、成本、售价的影响判别 -> 2023 预期销量与单位利润侧写 -> 年×地块×季次×作物面积变量 -> 成本 + min 正常销售 + λ·max 超量销售 -> 地块/作物集合 -> 面积、最小面积、集中种植、三类重茬、三年豆类、地块季次适宜性等十四类约束 -> 结构体染色体 -> 按地块候选组生成可行个体 -> GA 锦标赛选择/交叉/变异/父子合并 -> 早熟比例触发新基因注入 -> 两种销售口径利润 -> 轮作隔年结构 + 2023 极端基线复核 -> 四类年度变化率的均匀随机递推 -> 华北寒潮/干旱文献 -> 季节映射与作物类别损失 -> 亩产风险因子 -> 正常/寒潮/干旱三套候选 -> 利润波动指标裁决 -> 三组替代品与两组互补品 -> 价格驱动需求修正 -> 供需偏差对价格/成本的相反修正 -> 问题三增量模型 -> 问题二/三同口径比较 -> MATLAB 初始生成/修复/检查接口`

## 结果与检验摘录

- 问题一滞销和半价口径分别报告 29,276,719.5 元与 42,837,286.75 元。两种结果均先看进化曲线，再按销售口径解释作物结构。
- 滞销结果的合理性按三层推进：收敛曲线趋稳；轮作约束预言高利润年份至少相隔一年，逐年利润图回查；构造 2025/2027/2029 尽量复用 2023、其余年份只补豆类的极端基线，估算约 1788 万元，与当前方案比较。
- 半价情形在利润最高年份大量安排黄瓜；正文用黄瓜单位利润较高且超量仍可半价出售解释这一结构。
- 问题二正常、寒潮、干旱三工况利润分别为 41,310,782.4687、35,571,712.9128454、38,732,308.4505 元；再由利润波动指标比较三套方案，选方案 3。
- 问题三报告 37,304,570.2468 元，并与问题二逐年对照；正文把下降解释为供需关系与替代性促使买方转向低价农产品。

## 人类文风与判断轨迹

1. 数据补全先交代同源依据：智慧大棚第一季由题面“与普通大棚第一季相同”补全，处理动作、理由和下游用途连续出现。
2. 参数索引由两组对照表裁决：季次改变亩产、成本和售价；地块只改变亩产和成本。作者先读表，再决定哪些参数带地块或季次索引。
3. 约束按现实相邻关系拆开：重茬分跨年单季、同年双季和本年第二季到次年第一季；水浇地、普通大棚、智慧大棚和菌类另列季次限制。
4. GA 先给染色体和可行流程，再给 100 个体、200 代、10% 变异、10% 早熟门；早熟后插入新基因，交叉与变异后统一修复。
5. 结果验证不止收敛曲线，还用约束诱导的隔年形态和一个可解释的保守基线检查利润尺度。
6. 灾害参数有清楚来路：华北地域事实和文献给灾害，季节表给受影响季次，作物类别给损失率，最后只修改亩产。
7. 跨问承接列出冻结项：问题二沿用面积、轮作和适宜性，只改销量/亩产/成本/售价；问题三保留主体，只加关系接口。
8. 替代/互补先由价格--需求方向定义，再按用途分组，最后选择函数进入销量；概念、分组和参数各司其职。
9. 附录把可行性写成共享协议：初始生成、变异、交叉后修复和最终检查共同维护地块候选、重茬、豆类和销量阈值。

## 可迁移句式与去 AI 味

- “比较同一作物在不同季次和不同地块下的三项指标可知，季次同时改变……，而地块只改变……；因此在后续参数中分别保留……索引。”
- “不能重茬并非只有一种相邻关系：一季作物跨年相邻、两季作物同年相邻，以及本年第二季与次年第一季，三种情形分别约束。”
- “当最优适应度对应个体超过种群的……时，认为种群可能早熟；此时插入一批新个体，再重新计算适应度并排序。”
- “轮作约束意味着高利润年份不应连续出现，图中的隔年结构与这一预期一致；为进一步判断利润尺度，再构造……作为保守参照。”
- “灾害影响先由发生季节确定受影响季次，再由作物类别确定损失率，最后只修正对应亩产，其他接口保持不变。”
