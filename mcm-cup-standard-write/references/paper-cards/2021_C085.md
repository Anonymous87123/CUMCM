## 可调用的模型与写作动作

1. `统计量定义 -> 指标方向 -> 业务能力 -> 评价意义 -> 公式`：指标不能只列名称。
2. `规则 1 的稳定性含义 -> 规则 2 的异常排除作用 -> 同时满足 -> 期望值口径`：筛样阈值要承担具体角色。
3. `固定权重的具体失败模式 -> 当前周缺口 -> 下一轮权重`：算法改进先说明会在哪个状态失效。
4. `连续淡季位置 -> 前视窗口长度 -> 提前备料`：窗口长度来自数据。
5. `原始成本不可比 -> 点名产能差异 -> 成本/产能 -> 数值裁决`：比较口径须与方案产出一致。
6. `超容量大项预拆 -> 可靠性/价值排序 -> 背包装载 -> 残项贪心`：组合算法按角色接力。
7. `提前窗口 -> 延后窗口 -> 双向窗口 -> 条件性结论`：灵敏度结果回答当前窗口为何被采用。
8. `上、下层目标 -> 分阶段求解器 -> 中间接口`：不以“一个算法求解双层模型”遮蔽实现顺序。

## 人类惯用词及段落骨架

- `将……定义为……；……越大，说明……越强，越能保证……，进而……越重要`：把统计量、方向和业务含义接在一起。
- `本文设定了两个规则……在以上两个规则都满足的情况下，选择……作为……`：规则最终落到筛选口径。
- `若全局只使用一种贪心策略，可能会导致总体情况良好但是某一周……因此……根据……重新设置下一状态每周的权重`：由局部失败转入动态权重。
- `经过数据分析，发现第 7 周和第 8 周属于连续的供货淡季，因此……向前观察 2 周并提前准备材料`：用具体周次解释窗口。
- `已知的 240 周采购成本均值虽然略低……但由于其每周均值产能未达到……本文取采购成本与产能的比值作为判断标准`：先指出原始比较失真，再改口径。
- `先……再……求解完毕后……处理未能成功规划的材料`：按求解器角色交代接力。
- `由结果可见……由此可以判断……但比较……发现……`：灵敏度段给带条件的结论。

调用时只复用信息顺序，必须填入实际阈值、周次、容量、比值和裁决规则。
