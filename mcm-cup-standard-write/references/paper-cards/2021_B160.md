## 可调用的模型与写作动作

1. `曲线形态 -> 排除线性 -> 高阶解释/稳定性边界 -> 二次模型`：模型名放在推理末尾。
2. `保持条件 -> 唯一改变量 -> 点名比较组 -> 响应 A 读图 -> 响应 B 读图 -> 局部结论`：控制变量不省略可比性。
3. `无交互正交极差 -> 有交互二次回归`：前者排主效应，后者补因素耦合，二者功能分开。
4. `标准化 -> 交叉项线性化 -> 4:1 划分 -> 初始诊断 -> 点名共线性 -> stepwise 修正`：允许正文保留一次不理想的初始模型。
5. `R/R^2 -> RMSE -> F/p -> 因素解释`：相对、绝对和整体显著性三层不能互相替代。
6. `前文结果 -> 未闭合证据缺口 -> 单次实验 -> 预设裁决规则`：五次实验分别承担曲线外推、区间补测、两项响应组合检验和优化点确认。

## 核验结果

- 不计交互时，质量和对转化率影响最大，Co 负载量对选择性影响最大，装料比对两项响应影响均最小。
- 转化率回归：`R=0.91`、`R^2=0.832`、`RMSE=0.0417`、`F=39.74`、`p=6.17×10^-27`。
- 选择性回归：`R=0.89`、`R^2=0.80`、`RMSE=0.0453`、`F=36.03`、`p=1.14×10^-24`；验证集拟合值与实际值在图 16 对照。
- 全温区：406.9℃、400 mg、2 ml/min、1.4 wt%、装料比 1.4，收率 56.3%。
- 不高于 350℃：210.3℃、400 mg、2 ml/min、1.9 wt%、装料比 1.8，收率 29.8%。p.19 原始栅格确认第二次温度约束为 `50<=T<=350`。
- D1/D2 分别检查 325℃后走势和补 450℃缺口；D3/D4 分别检验转化率/选择性正交组合；D5 比较优化点实际与理论收率。

## 人类惯用词及段落骨架

- `通过对……数值变化趋势判断可知……但是……因此……`：观察、排除和选择在同一因果链。
- `又由于……因此为了……此处选择……`：解释复杂度边界，不作空转折。
- `当……相同、……相同，只改变……时，将……组进行对照`：逐项建立可比性。
- `由图……可以看出……；在同一温度下……；从整体来看……`：完成双响应读图后才收束。
- `由图……可以看出由于……存在多重共线性，因此进行逐步回归，剔除……`：诊断点名问题，随后给修正动作。
- `从回归的相对效果看……；从绝对效果看……；从方差分析方面看……`：各指标承担不同判断。
- `若……则说明……，具体因素取值见……`：把实验结果与前文判断绑定。

起草时只复用信息顺序，所有省略处必须替换为真实变量、组别、图表、数值和裁决标准；不得把这些句式批量铺在相邻段落。
