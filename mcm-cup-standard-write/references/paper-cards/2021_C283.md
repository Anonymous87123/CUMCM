## 可调用的模型与写作动作

1. `便利假设 -> 容量/数量事实 -> 需求矛盾 -> 修正假设`：假设段允许保留作者自我纠正的过程。
2. `指标名 -> 数据操作 -> 零值/异常处理 -> 方向 -> 业务意义 -> 后续用途`：评价指标不是天然存在的名词。
3. `客观权重 -> 具体异常 -> 业务冲突 -> 有限主观修正 -> 一致性检查`：主客观组合须由异常触发。
4. `线性规划变量/约束边界 -> 动态规划状态空间 -> 已有目标优先级 -> 双层贪心`：被舍弃方法提供选择依据。
5. `满意边界 -> 达到即停止 -> 继续增加的采购、运输和库存后果`：停止条件须有业务代价。
6. `共同历史基准 -> 候选机制 -> 同程序比较 -> 约束/成本/初期稳健性 -> 现实性裁决`：不能只报最终公式。
7. `多次运行 -> 频率较高且目标较优 -> 典型代表方案`：随机输出不伪装为确定性唯一最优。
8. `方向需要 -> 权重下界 -> 权重上界 -> 过度偏置牺牲项`：人为方向权重必须有双边界。
9. `旧目标 -> 新目标逆转 -> 低排名候选重新有用 -> 范围扩张`：候选范围跟着任务语义改变。
10. `预期瓶颈 -> 实际停止条件 -> 两种可能解释` 与 `两曲线同向 -> 定量滞后 -> 库存传导`：结果段保留真实疑问和时序判断。

## 核验结果

- 176 家供应商由九项指标评价，熵权结果经绩效、战略意义和潜力三类准则有限 AHP 修正，并通过一致性门。
- 问题二报告平均采购成本 20488/周、运输损失 135.33/周；合作供应商约 16 家，范围 10--25。
- 四个关键式中，B 违反约束，D 成本高且初期稳健性弱，A/C 接近，最终取定义更贴近实际的 C。
- 问题三以 A/B/C=`1.05/1/0.95` 重排并在 5% 邻域替换 C，报告 A/C=7.34、损耗 72.73/周。
- 问题四扩至 176 家，报告平均动态产能 43299、较 28200 提高 53%，平均接收产能 43667，生产曲线约滞后 3 周。

## 人类惯用词及段落骨架

- `由题可知……；而由……可知，若假设……，则……难以满足……，故原假设不成立`：用矛盾修正假设。
- `……比单纯计算……更有意义，它去除了……而导致的……情况`：指标定义同时交代数据处理。
- `但根据实际操作结果来看，这难免会出现与事实不吻合的情形，需要在适度范围内修正`：由具体异常进入权重修正。
- `若选择……则……；若考虑……则……。分析题目发现……，故……`：比较被舍弃方法后选算法。
- `一旦大于该产能立即“见好就收”，停止增加订单`：停止边界后必须续写额外采购/运输/库存的后果。
- `公式 A 与 C 的结果均较为可观且相接近，但公式 C 的定义更加贴合实际，故最终选择……`：数值接近时用机制裁决。
- `基于此方案，多次实验求得相关目标值。选取频率较高且目标较优的典型代表方案……`：限定随机结果强度。
- `一方面……不可过小，确保……；另一方面设定值不可过大，否则……`：定向权重写双边界。
- `但是鉴于此问目标逆转……故我们考虑……`：目标变化带动候选范围变化。
- `后者的波动趋势与前者几乎相同，整体滞后约 3 周`：比较曲线并量化时滞。

调用时只复用信息顺序，必须填入实际容量、对象数、指标、阈值、候选机制、代价和曲线读数。
