## Four-question model chain

1. **Heave:** ground/body-fixed coordinates; wave excitation, added mass, radiation damping, hydrostatic restoring and PTO spring/damper; two second-order coupled equations converted to four first-order states; RK4 with `h=0.0001`, 40 wave periods, output every `0.2 s`.
2. **Linear/nonlinear damping:** average PTO power over a stable interval; trapezoidal discretization; coarse damping sweep first, then genetic algorithm. Reported Q2(1) `229.6819 W` at `C_h=37639`; Q2(2) `230.0163 W` at `C_h=81478`, `alpha=0.3377`.
3. **Heave plus pitch:** compute the composite buoy centroid from disk/cylinder/cone pieces; use parallel-axis and perpendicular-axis theorems. Buoy centroid `(0,0,2.2079)`, buoy pitch inertia `8289.43 kg m^2`, oscillator origin inertia `1571.3125 kg m^2`; solve eight state variables by RK4.
4. **Two damping coefficients:** combine translational and rotational power; use `100--180 s` stable window and GA with both coefficients in `[0,100000]`. Reported `Pmax=316.5807 W`, `C_h=58944`, `C_p=98227`.

## Verification and code interface

- Period check: zero-crossing intervals are compared with `2*pi/w`; reported errors are `0.0017`, `0.0034`, and `0.00036` for the three tested cases.
- Reliability: perturb the pitch inertia by `+/-1%`, subtract standard outputs, and plot heave/pitch velocity deviations.
- Appendix interface: parameter initialization -> state arrays -> RK4 loop -> state plots -> 0.2 s sampling -> Excel output; GA wrappers call objective functions that solve the ODE and integrate power on the stable window.

- Question-by-question progression uses “首先……其次……最后……” and “在问题一的基础上……”.
- Formula explanation follows the displayed equation: each RK4 slope is named and its role is stated; “易知” is used for the midpoint weight conclusion.
- The stable window is justified by the observed transient: “由于前期位移不稳定……故截取(100,180s)”.
- The solver transition is explicit: a larger step is used for a rough landscape because exhaustive search is slow; GA is then introduced for a more accurate optimum.

- Validation is a rule, not a slogan: define zero crossings, define period error, then state “若方差较小，则可验证认为模型正确”.
- Sensitivity is motivated by an error source: “考虑到计算浮子转动惯量时会产生一定的误差，故……添加±1%的扰动”.
