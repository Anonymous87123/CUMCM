## 可调用的模型与写作动作

1. `现实中两类偏差后果不对称 -> 列函数条件 -> 构造分段损失 -> 正向化为评价指标`：先让函数形状服从业务后果。
2. `观察规律 -> 解释可能成因 -> 说明为何不进入后续模型 -> 给出干扰和任务变化两条理由`：分析不等于全部纳模。
3. `企业历史状态 -> 初值不能归零 -> 历史同周期位置 -> 初始库存估计`：初值须有业务身份。
4. `先检查时间记忆 -> 再逐周拆分`：可分性不是为了省事而假设。
5. `尾部数量级 -> 头部覆盖比例 -> 扩大候选集的代价 -> 固定候选范围`：范围裁剪给数量依据。
6. `单目标化与多目标算法两条路径 -> 点名主观性边界 -> 选择 MOPSO`：方法选型写清被舍弃方案。
7. `24 个逐周最小数取最大` 与 `24 个逐周最大值取最小`：聚合方向由“统一集合”和“每周可达”两种语义决定。
8. `递推关系 -> 本期超量 -> 下期决策收缩 -> 状态稳定`：把约束的实际作用翻译出来。

## 核验结果

- 非对称订供偏差函数为 `e^x-1 (x>=0)` 与 `e^{-2x}-1 (x<0)`，缺供侧惩罚更陡。
- 投影方向为 `[0.414,0.310,0.566,0.235,0.577,0.131,0.007,0.085]`，前 50 家进入候选集。
- 逐周 0--1 规划的最少供应商数取最大，得到至少 24 家。
- 经济订购报告平均采购单价 1.0925，低损耗转运报告平均损耗率 0.2143%。
- 问题三报告 A 类占比 79.95%、C 类占比 2.3%；问题二对应为 57.69% 和 15.79%。
- 24 周最大等效产能为 73859--74036，论文报告平均约 73944，较原产能提升约 45744；转运能力为瓶颈。

## 人类惯用词及段落骨架

- `为了体现出……的影响明显重于……，本文在……的基础上设定……`：从业务后果进入非对称损失。
- `由于……的正负对……造成的影响不同，所以……满足下列条件。综合考虑以上条件和生活实际，构造出……`：先条件，后函数。
- `为了反映……，本文……，从而得到……的列向量`：指标定义同时交代数据操作和维数。
- `容易发现……拥有各自的……，但在下文的分析中不单独分析，原因有如下两点`：主动说明不纳模的规律。
- `考虑到企业并非刚刚成立……因此不能简单地认为……为 0`：初始状态回到真实业务。
- `由于……无记忆，即……不会影响本周……，所以……只需要……；为了简便计算可以一周为单位考虑`：先证明可分，再拆分。
- `考虑到将多目标直接化为单目标主观性太强，采用……求解模型`：选型段写出边界。
- `这里应选用其中……的作为……，以确保每周……`：局部解聚合到全周期保证。

调用时只复用信息顺序，必须填入实际方向、函数条件、覆盖比例、周次、状态变量和裁决规则。
