# 2022 B086: local-information geometric positioning and formation adjustment

## Evidence scope

- B problem, 32 pages; p.1--32 were manually read, including the Python appendix.
- Evidence IDs: `EV-20260730-B086-01`, `EV-20260730-B086-STYLE-01`.
- Original embedded JPEGs for p.6, 10, 12, 18, 19, 22, 24, and 25 were checked.

## Model chain

`polar sine-law positioning -> two analytic symmetric solutions -> ID/order-based disambiguation -> regular-nonagon angle-set emitter identification -> radial preprocessing with a 5% bound -> two local squared-angle-error search schemes -> ex-post global evaluator -> convergence/stable-error/resource-proxy decision -> three geometric lemmas -> lemma-to-drone-group assembly -> 3-D local search -> plane-fit check -> ten Gaussian perturbation sets`

The local objective contains only angles observable by the receiving drone. The global error is computed after simulation for comparing schemes and is not used by any drone to adjust its position; this distinction preserves the non-sharing information assumption.

## Reported results

- Within a `+/-5 deg` receiving-angle error, only one additional emitter beyond FY00 and FY01 is required.
- Radial preprocessing reduces the stated `+/-15%` radius error to about `+/-5%`; the checked page gives `O'_j/R <= 1.049`.
- The square search neighborhood has side `a=0.2` and step `b=0.01`.
- Scheme 2 reduces the global error from `0.0969` to `1.90e-6` in its first cycle and stabilizes near `5.96e-6` after roughly six cycles.
- The reported search/transmission proxies are `134400` for scheme 1 and `25600` for scheme 2, so the latter is about 19% of the former. They are comparison proxies, not real adjustment counts.
- The conical-formation plane-fit value decreases from `3.893` to `0.206`, a reported reduction of 94.7%.
- Ten Gaussian-perturbation data sets converge in the paper-reported `1e-7--1e-5` range.

## Human style rules extracted

1. Start a subsection with a plain classification such as `该问本质上是一个……问题`, then immediately name the unknowns and equations.
2. Write information legitimacy as `non-sharing -> local observable vector -> local objective -> ex-post global evaluator -> why the evaluator is not used for action`.
3. After proving a preprocessing error bound, state the second payoff: a smaller search region and fewer signal/computation evaluations.
4. Compare schemes on the same initial data and in a fixed order: convergence speed, stable error, resource proxy, proxy disclaimer, decision.
5. Map every geometric lemma to fixed points, adjusted points, controlled angle/ratio, target geometry, and concrete drone groups.
6. When one initial data set is insufficient, state that limitation before defining perturbation distributions, repeated data sets, convergence range, and scope.

## Boundaries

All numbers are paper-reported and raster-checked rather than independently reproduced. The global metric is evaluation-only. The finite local grid is not a certificate of a continuous global optimum.
