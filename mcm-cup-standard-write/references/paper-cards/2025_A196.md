## 实际模型链

`导弹/无人机/烟幕弹/云团轨迹 -> 圆柱表面视线与球体相交 -> Bool(t) -> 时间积分 -> 连续区间证明 -> 外轮廓 -> 凸截面证明 -> 上下底面圆周 -> 面积误差 + 点数敏感性 -> 二分起止时刻 -> 航向/速度/投放/起爆四变量 -> 多起点变步长坐标搜索 -> PSO 对照 -> 单机三弹时序与云团并集 -> DE -> 多机单弹 12 维模型 -> 预测拦截点重合 -> 比例系数降维 -> 局部网格微调 -> DE 对照 -> 多机多弹多目标 45 维模型 -> 理论可用时间收益 -> 整数任务分配 -> 三个导弹子问题 -> 有效区间汇总`。

## 结果与检验摘录

- 问题一为 `1.391643 s`；100/200/300/500/1000 点对应 `1.391646/1.391644/1.391643/1.391643/1.391643 s`，300 点内接多边形面积相对误差为 `0.00731%`。
- 问题二主算法为 `4.587300 s`，参数为 `0.0902 rad`、`136.3663 m/s`、`0.8977 s`、`0.0497 s`；PSO 为 `4.587772 s`，正文报告相对误差 `0.01%`。表后继续归纳高速、小角度和早投放的共同结构，并用导弹--目标视线解释。
- 问题三为 `6.93586 s`，表格逐枚给贡献；正文识别主导烟幕弹，并以相遇时序解释后续弹的有限作用。
- 问题四预测拦截点加局部网格为 `11.125936 s`，DE 对照为 `11.645260 s`，正文报告相对误差 `4.46%`；三段作用区间互不重叠，形成时间接力。
- 问题五先构造理论可用时间并整数分配，再拆三个子问题，报告 `21.0770 s`。

## 人类文风与判断轨迹

1. 布尔函数不是装饰：任意圆柱点的视线相交条件成为 0/1 状态，积分直接统一一个或多个有效区间。
2. 二分法前先证明遮挡关系只经历一次进入和一次退出；算法由连续单调结构授权。
3. 几何简化保留“外轮廓--截面圆盘--凸性--上下圆周”的证明链，不用“近似处理”跳步。
4. 离散点数先看内接多边形面积误差，再重算最终时长；理论近似和任务输出共同裁决工作点。
5. 自编搜索按“多起点--正负坐标测试--择优--无改进则缩步--局部解间比较”写成可执行协议。
6. 算法对照表后先找共同参数结构，再从视线几何解释策略，并说明微小角度偏差为何对准圆柱轮廓而非中心。
7. 多弹结果逐枚读贡献，定位主导弹和未生效弹，再由相遇时序与空间位置解释。
8. 12 维问题先用预测拦截点给近似解，再在近邻网格求完整圆柱判定下的结果；近似只生成起点。
9. 45 维问题先把飞行时间挤占云团寿命写成收益，再做整数任务分配和子问题分解。
