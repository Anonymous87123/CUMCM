## Model chain

`sine-law polar model -> four-region case burden -> two fixed-chord/fixed-angle circle loci -> rotation/cross-product center selection -> symmetric second intersection -> error-tiered emitter decoding -> short-arc and interval certificate -> three/four-emitter position adjustment -> squared-distance L2 objective -> depth-threshold look-ahead search -> five-round / 16-transmission practical stop -> degeneracy audit for the conical formation -> predetermined emitter order and FY13 special round -> randomized initial-error simulation`

The “decision tree” on p.17 is a search tree. Nodes are formation states with an L2 value and edges are emitter choices; it is not a trained prediction tree.

## Reported results

- The circular adjustment threshold is `10^-4 m`; the objective is `L=sum_{i=1}^{9} d_i^2`.
- Greedy and thresholded look-ahead reach about `10^-6 m^2` by decision 4; random selection requires about 20--30 decisions for that scale.
- Six rounds yield a reported L2 loss near `10^-23 m^2`, but the practical plan stops after the first five rounds and 16 emitter transmissions.
- The decoding certificate combines a circle/`2°`-sector intersection, a proof that the third-angle range is at most `2°`, and exhaustive disjoint interval tables.
- For the conical formation, the paper compares `0.5 m`, `1 m`, `3 m`, and `5 m` initial errors, reports 10,000 runs, and describes high-precision convergence after about 60 adjustments.

## Human style rules extracted

1. Show the old method's incompatible case formulas before switching methods; let visible computational burden authorize the change.
2. Follow `注意到` with a usable invariant and its immediate computational consequence.
3. Build an error argument as `specific numeric case -> geometric intersection -> endpoint bound -> exhaustive interval table`.
4. Allow the rejected algorithm a local advantage, then explain the concrete action that reverses the global comparison.
5. Separate numerical convergence from practical stopping: state the extra precision first, then the task threshold, transmission cost, or interference that makes further computation unnecessary.
6. Before reusing an earlier model, list degeneracies, their failure mechanisms, and the protocol changes that repair the interface.

## Boundaries

All numerical results are paper-reported rather than independently reproduced. Body-level error tiers and the broader abstract summary remain distinct. Appendix OCR is used only for module/data-flow confirmation.
