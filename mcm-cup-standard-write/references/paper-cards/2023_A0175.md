- Evidence IDs: `EV-20260730-A0175-01`, `EV-20260730-A0175-STYLE-01`.

## Model chain

`solar position -> incident/reflected central rays and mirror normal -> ground/mirror/conical-beam coordinate transforms -> sampled conical rays -> tower shadow -> 20 m adjacency pruning -> incident shadow -> reflected blocking -> receiver interception -> optical efficiencies and DNI/output -> grid-step and height sensitivity -> common-size optimization -> annular honeycomb layout -> global rotation -> 10%×10 Monte Carlo coarse evaluation -> freeze weak μ/h variables -> search w=v and tower position -> 30%×5 finer evaluation -> threshold-feasible design and high-blocking-mirror pruning argument -> inherit Q2 layout -> raise outer/northern mirrors`

GA, PSO, SA, neural networks, and a residual test are not implemented. Monte Carlo is used to sample mirrors and reduce the optical-kernel workload.

## Reported results

- Q1 optical, cosine, shadow/blocking, and truncation efficiencies are `0.536230167/0.756465488/0.913639403/0.889165521`; output is `32.76117051 MW`, with `0.521508604 kW/m^2` unit-area output.
- Q2 uses tower `(0,-250)`, `6×6 m` mirrors at `4 m`, 3311 mirrors, and `119196 m^2`; the efficiencies are `0.591643667/0.86829375/0.893479917/0.874777083`, output is `68.24427914 MW`, and unit-area output is `0.572538333 kW/m^2`.
- Q3 retains 3311 mirrors and `119196 m^2` while raising outer mirrors. The efficiencies are `0.496428083/0.825065333/0.894257083/0.778596417`, output is `60.336111 MW`, and unit-area output is `0.506192417 kW/m^2`.
- Grid steps `6,3,1.5,1,0.5,0.25 m` give unit-area outputs `0.29982404,0.35749342,0.37905415,0.389954,0.39836452,0.40294417`; the paper selects 1.5 m after the gain begins to flatten.
- Heights `3--6 m` change the same indicator only from `0.35798` to `0.35641`, which is used to freeze height during the main search.
