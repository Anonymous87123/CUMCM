# 语料重合复核

获奖论文语料只能学习结构、判断动作和节奏，不能搬运原句。本复核器比较新稿正文与 59 篇论文的逐段文本，发现达到阈值的连续字面量重合后，给出论文编号、页码、段落标识和片段。

```powershell
python scripts/audit_corpus_overlap.py main.tex --min-chars 20 --format text
```

默认阈值是 20 个归一化汉字/字母/数字字符。命中状态为 `review`，不是“抄袭”判定：术语、题面固定定义和公共表述也可能重合。交付前逐项处理：删除不必要的复刻、改为本题事实组织，或保留确属必要的固定表达并在复核记录说明原因。

正式候选在人工选定前使用 `--fail-on-overlap`。该选项只阻止尚未裁决的长字面量重合进入发布链；它不判断作者身份、近义改写、数学正确性或文风自然度。

本工具不把获奖论文当作可复制模板。语料检索仍应取少量同题型、同动作的段落及相邻上下文，只迁移信息组织和停止位置。
