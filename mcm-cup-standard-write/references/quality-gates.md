提交稿还须读取 [contest-rules-2026.md](contest-rules-2026.md)。以下数学、数据和写作门用于检查内容质量，不能替代版式、匿名、支撑材料与 AI 声明检查。

## 1. 证据门

- 所有关键数字能定位到题面、附件、日志或结果文件。
- OCR 不可靠内容标“未确认”，公式和表格回看原始栅格。
- 赛题、编号论文、专家评述三类来源没有混用。
- 引用条目能支持其前面的具体主张。
- 参考文献之前保留且只保留一种与实际情况相符的“AI 工具使用声明”；使用过 AI 时，支撑材料含 `AI 工具使用详情.pdf`，其用途、过程、采纳、人工修改和核验能与正文及代码对应。

## 2. 数学门

- 变量、参数、索引、单位和取值域完整。
- 方程量纲一致，目标方向正确，边界/初值齐全。
- 所有业务要求映射为约束、目标或结果检查。
- 为关键符号、单位、目标方向、求解器约束、正文--代码变量映射和独立数值复算建立 `math-contract.json`，运行 `audit_math_semantics.py`。该契约只核对明确列入的语义接口，不得据此宣称整个模型已经证明正确。
- A 类几何/结构题建立“题面硬约束--公式--代码检查--结果残差”映射表；固定拉索长度、相邻节点距离变化率、行程/力限值等不得只出现在题面或重述中。
- A 类链式几何的多根方程须列候选根、构件前后顺序、方向/单调条件和局部连续性；只写“取合理根”不通过数学门。首次碰撞/失效缩域须证明最早事件只可能落在保留对象中；不能仅以“降低复杂度”删除其余对象。
- 回退求精须保存初值、范围、粗步长、越界判据、回退动作、缩步比例、停止阈值、最终可行点和首个不可行邻点，并把停止阈值映射到物理误差上界。
- 若相切、守恒或比例约束使目标量唯一，应给不变量证明并明确当前约束下无优化自由度；不得为满足“优化”措辞虚构启发式搜索。跨区域复用逐项核对不等式、坐标符号、切向方向、初值和边界；齐次缩放先证明局部倍率传递。
- 先区分硬约束、软约束和有依据的松弛。任一硬约束超限时，候选不得直接称可行方案；至少报告最大违约、通过率、超限位置/对象、松弛依据和修复代价，并在修复后重新验算目标。
- 控制输入方向与状态位移方向分开定义。若促动器沿径向动作，不得未经结构兼容、连接关系和整体平衡就断言节点位移也沿径向。
- 坐标旋转、偏轴曲面或反射几何用中心点、顶点和至少一个非对称点核对正负号、旋转方向、距离不变量和节点标识；不得依赖固定行号保存特殊节点。
- 每个备选模型标记“提出、推导、实现、求解、验证”状态。只给思路或变换式而未运行求解的模型不能写入已完成模型链，也不能共享另一模型的结果。
- 几何接收率须闭合“入射方向--面板法向--反射方向--馈源面交点--覆盖/重叠”物理链；若改用投影面积比等代理指标，应明确缺失机制、误差方向、适用边界并与光线追迹或可验证基准对照。
- 任何经验修正系数须记录定义、来源、标定样本、适用几何/工况、区间与不确定性；不能用无来源常数把基准调到期望数量级后再把结果称为物理接收率。
- 线性化、松弛、近似和数值离散的误差有说明。
- 极端输入、退化情形和小规模手算能够通过。
- 对 `min(max(...))`、`max(min(...))` 等嵌套极值，用两三个候选的手算小例同时核对内外层方向、索引与最终导出行，变量名中的 `Max/Min` 不作为方向证据。
- RMS 明确误差对象、样本数与公式 $\sqrt{n^{-1}\sum_i e_i^2}$；均方、均方根、绝对误差和最大偏差不得混名。
- 公式名称、公式本体和代码实现一致：RMSE 必须包含残差平方，PDE 的自变量与导数阶数正确，正文交叉引用指向实际使用的式子。
- 灵敏度表逐参数解释方向和量级；不能在某个相对灵敏度明显大于 1 时只写“整体稳定”。
- 拟合、约束检查、局部扰动、随机重复和外部验证分级表述，不用样本内 `R^2` 代替泛化验证。
- 数值 PDE 写清时间/空间差分类型、边界离散、线性系统和网格收敛；公式求和项数与归一化分母逐项核对，不能把 `N+1` 个样本默认除以 `N`。
- 标定参数同时检查单位、物理量级、图轴范围和代码常量。拟合参数若缺少可辨识性证据，只称等效参数，不赋予材料常数含义。
- 集总参数模型必须给出 Biot 数、特征时间尺度或相对高阶模型的误差依据；时间常数应为正，同一符号不得在传热系数与等效冷却率之间无声明换义。
- 阈值交点、峰值和积分上限由连续定义转成离散索引时，写清越界定位、插值/求积格式、步长及误差；峰值约束默认检查 `max`，除非固定位置等价性已证明。
- 终点库存、残值、回收费率和补购价格必须进入同一目标口径；“剩余有损失”不能推出整数库存必须恰好清零。若施加终值等式，先证明其可行且不删去更优解。
- 图搜索、动态规划或枚举声称全局最优时，证明初始资源、路径、停留/挖矿和补给动作覆盖完整可行域；只扫容量边界或预选路线时，结论限定为候选集最优。
- 随机动态决策逐时刻写明信息集。使用整段未来情景求得的路径或动作只能称离线全知解/上界；在线策略不得读取决策时尚未发生的天气或需求，并应在独立情景上报告相对离线上界的遗憾、失败率和尾部损失。
- 马尔可夫链由 `N` 个连续观测估计时，相邻转移计数总和必须为 `N-1`；逐项核对原始计数、状态顺序、计数矩阵行和与转移矩阵。稳态分布只能解释长期占比，不能无验证地充当逐日预测。
- 随机目标先定义一项满足非预见性的策略，再对该策略取期望；不得对每个完整未来情景分别求全知最优后以 `max(P_W C_W)` 等式冒充期望。期望库存大于零也不能证明每条路径可行，须另报缺货概率、分位数或机会/鲁棒约束。
- 样本均值、方差、标准差和比例公式逐项核对归一化分母、平方与平方根；指标名称、量纲和代码实现必须一致，不能把未除样本数的加总称均值，也不能把方差称标准差。
- 风险模型逐项列出 `PD`、`LGD`、`EAD` 的定义域和单位；若 `LGD` 已含授信金额，就不能再与 `EAD` 相乘后仍称期望损失率。检查每一项乘积的最终单位，并用极端金额测试是否出现无依据的平方增长。
- 风险乘数逐项声明是相对增量还是总倍率。正文若写 `(1+Q)`，代码、单位表和约束须在 `Q=0`、标定值与边界值处同值；直接以 `q` 替换而无映射时，阻断情景结果与最优性结论。
- 百分位阈值写清原序列的升/降序、样本量 `n`、秩定义、目标尾部和并列值处理。降序第 `k` 位通常对应升序上尾分位，不能直接称“第 `k` 百分位”；还须用标签或外部损失验证阈值方向。
- 多人决策先判定共同收益、一般和、零和、拥塞或合作结构，再把支付定义映射到题面目标。不得在“效用相同、无竞争”假设下无说明地改用对手最小化本方收益的极小极大模型。
- 混合策略的概率本身就是解；若业务要求落成确定动作，应另给抽样、相关均衡、风险准则或二阶段选择规则，不能直接取最大概率并主观破平局。
- 有限博弈先列最佳反应与严格/弱支配关系，再枚举纯策略均衡，最后求内点混合解并检查概率是否位于 `[0,1]`。负概率或大于 1 只说明该内点解不存在，不能据此断言没有纯均衡或边界均衡。
- 严格支配关系须对每个对手动作逐列比较同一玩家的两个策略；全局最大值或列最大值不能替代该定义。任意指数收益、势场系数或人数缩放须给归一化、校准依据与敏感性结果。
- 多阶段博弈若存在库存、位置、现金或历史信息跨期传递，须建立联合状态、策略与子博弈结构；逐日局部支付矩阵只有在阶段可分条件成立时才能外推为全局策略。
- MDP 状态满足充分性：给定状态和动作后，回报与下一状态分布不再依赖被省略的历史。用同位置但不同库存、现金、日期、天气/其他玩家状态的反例测试；若动作集或转移不同，扩展状态而不是继续宣称马尔可夫性。
- 多目标必须通过加权、词典序、约束法或 Pareto/偏好选择闭合。只并列“总收益最大、方差最小”而不定义优先级或候选裁决规则，不能产生唯一最优方案。
- 离散放贷/选择变量若被删除、连续松弛或阈值化，必须说明与原问题的关系并报告恢复后的可行性、目标差距和约束残差；连续求解器不能自动证明整数规划最优。
- 可选贷款、流量或分配须保留准入变量。若未选择时 $x_i=0$、选择后下界为 $L>0$，采用 $Lz_i\le x_i\le Uz_i$ 或等价逻辑；不能用 $x_i\ge L$ 强制全选后又在结果表列零值。
- 关键损失假设、风险阈值或约束不得因当前结果“不够可贷/不够好”而反向改写。确需变更时，回到假设和参数表说明外部依据、替代情景及对解的影响。
- 所有求解后折扣、取整、截断或人工调整都视为新决策。重新检查变量域、预算、逻辑一致性和目标值；若不重求解，只能称可行性未知的后处理方案，不能称原模型最优解。
- 迭代步长递减、目标曲线趋平或相邻解差变小只能支持当前轨迹趋稳；没有全局下界、可穷举小实例、最优性证书或充分的多起点对照时，不得升级为全局最优结论。

## 3. 数据与代码门

- 数据字典、缺失/异常/重复处理数量可追溯。
- 文件名、题面说明和附件实际字段不一致时，以读取到的列名、取值范围、末年和记录粒度为准，并把差异写入数据边界；不得按题面预期补造附件中不存在的年份或字段。
- 同一附件中的表可承担不同角色。国家级目标、项目归属、参赛规模和情景参数分别指定唯一来源；团队项目在运动员行中重复出现时，先判断记录粒度，再决定去重键，不能把运动员获牌行直接汇总成国家奖牌数。
- 监督标签逐行追溯到附件字段或明确生成规则，保存实体索引、正负类计数和对齐检查。按行号切片人工生成 0/1 标签时，阻断监督预测、准确率和外推结论。
- 模型名称、目标/损失与拟合 API 一致。正文称 Logistic/二项分类而代码调用普通最小二乘 `regress` 时，须改用二项拟合接口，或按实际线性回归改名并重新裁决输出域与指标。
- 训练、验证、测试隔离；预处理只在训练折拟合。
- 训练、验证、测试的实体/时间索引分别保存，并以集合交集断言互斥；任何测试切片与训练切片重叠时，测试指标立即降级为回代或非独立指标。
- 外层测试集在补全、缩放、降维、特征选择、校准、阈值或集成权重学习前冻结。所有 `fit`、调参和权重计算仅使用训练/内层验证折；发现全体数据 `fit_transform` 或全体/综合指标进入权重时，最终测试指标立即失去独立性。
- 每个估计器保存“构造/载入--参数确认--拟合--首次预测--计分”的调用顺序。构造后首个调用即为 `predict`，或参数字典含库版本不识别的键时，阻断相应预测与比较结论。
- 投票、堆叠或加权集成保存每个基学习器的内层折指标、权重公式和归一化结果；外层测试不得参与基学习器筛选、权重或校准。AUC 使用连续概率/决策分数，硬标签 AUC 不替代排序性能。
- 随机种子、软件版本、参数和停止条件记录完整。
- 建立 `repro-manifest.json`，至少记录实际运行命令、Python 与主要库版本、随机种子、生成时间、数据清洗配置，以及分析脚本、结果、图表和配置文件的 SHA-256。运行 `audit_repro_manifest.py`；任一文件哈希变化后，旧图、旧表和旧正文均须重新核对。
- 离散事件仿真为每类资源分别保存可用时刻、动作起止、占用对象和状态更新顺序。允许并发的加工、清洗、移动不得误压成串行；用一段可手算短日志核对事件先后和携带/库存状态。
- 产量、目标积分、忙碌、等待和动作日志必须共享报告终点。最后一个动作跨过班次或仿真边界时，各累计量只计边界内部分，并独立检查时间会计（如 `busy+wait=H`）和计数单调性。
- 主表数值可由干净运行复现；输出文件满足题面格式。
- 附录说明入口脚本、输入输出和目录结构。
- 约束条件做静态真值检查：区间外判定应为 `<L || >U`，发现 `<L && >U` 等永假/永真分支立即阻断提交。
- 邻域或状态转移的分支编号无重复、无遗漏；每个动作由最小单元测试触发一次，并核对只改变预期变量。
- 双重循环和分支中的行列索引逐句核对；条件使用 `j` 而赋值读取 `i`（或反之）时，用非方阵、非对称手算矩阵触发各分支，防止同值样例掩盖错行。
- 正文声称二分、A*、遗传、退火等算法时，附录必须出现该算法的决定性结构；只有优先队列不能自动称为 A*，只有随机扰动不能自动称为遗传算法。
- 摘要、正文、结果表和附录常量中的关键数字做双向一致性扫描，冲突项回到结果文件定值。
- 分析脚本每次干净重跑后，先核对结果源哈希，再核对摘要、结果段、表格、结论和附录中的关键字面量。旧结果清单与当前源哈希不一致时阻断编译交付；不得因 PDF 已生成而继续沿用旧稿数字。
- 附录函数的定义参数与调用参数一致；未注释入口能从声明的输入生成正文结果。被整体注释或接口不闭合的代码不能作为可复现证据。
- 随机优化至少记录种子、运行次数、可行率、最好/均值/标准差/最差和停止原因；列出多次结果后只选择最好一次，不足以证明稳健或避免局部最优。
- 对正文阈值、变量域和单位与附录常量做双向扫描，例如 `190/180`、`245/225`、`cm/min/℃`；任一冲突都先阻断最优性和可行性结论。
- 评价方法建立“公式步骤--核心算子--代码位置--输出列”追踪表。TOPSIS 至少应出现正负理想解、两类距离和相对贴近度；若实现只有归一化、熵权和加权和，就按实际算法命名。输入列数、归一化循环上界和权重维度必须一致。
- 正文样本量、筛选后样本量、代码数组长度、循环次数和分组大小须可互相还原。固定长度向量或逐组复制不能与“过滤后 `n` 个对象、每组约 `m` 个”同时成立而不解释映射。
- 有序分类须核对标签编码、输出层激活、损失、输出值域和切分阈值。连续回归相关系数不是分类准确率；至少报告混淆矩阵、逐类召回、宏平均指标或与误判成本一致的指标，重点检查少数类。
- 随机算法分别记录总提案数、接受数、温度层/代数和函数评估数；程序只在接受时自增的计数器不得标成总迭代次数。算法若声称局部邻域搜索，候选生成必须依赖当前解，而不是每次从全域独立重采样。
- 随机情景的经验概率、独立性/相关性假设、截断条件和生成器逐项一致；至少用频数或分布检验确认代码生成的样本服从声明机制，并检查写入/读取下标覆盖同一时间区间。
- 蒙特卡洛检验至少报告独立重复次数、种子或种子策略、均值、标准差、分位数/区间、可行率或失败率，并与确定性基线或留出情景比较；一条随机样本只称示例，不称验证。
- 蒙特卡洛正文样本数、代码循环上界、独立重复次数和结果分母建立四方映射；正文声称 $10^5$ 次或“多次取平均”而代码只执行另一数量级或单次时，阻断精度与稳健性结论。样本量加倍后还应检查均值/区间变化。
- 计数与比例必须共享可核对的分母：类别计数之和等于样本量，比例乘样本量在舍入容差内还原为整数；筛选、剔除或只统计成功样本后，明确新分母和条件事件。报告置信区间时同时给原始计数与重复次数。
- 所有概率、权重、目标和期望的中间表必须为有限数；发现 `Inf`、`NaN`、负概率、概率大于 1 或归一化和偏离 1 时阻断后续结论。零概率不得改写成无穷后继续参与期望运算。
- 对手设概率函数做定义域网格与边界值测试，输出最小值、最大值和越界样本；正文公式、附录公式与执行代码须在同一测试点数值一致。经验评分/冲击矩阵须记录赋值者、尺度、聚合顺序和归一化常数，正文声称的归一化必须在代码中出现。
- 为跨正文、代码和结果表的经验乘数建立映射表，至少列公式编号、代码函数、参数含义、单位、零值/典型值/边界输入、对应输出和差异裁决。语义不同但数值偶合不算同式验证。
- 建立正文公式--执行代码--结果表三方同源测试：同一输入下核对目标各项、约束方向、对象规模、索引范围、单位和展示值。任一方使用不同收益式、123/302 等不同规模或不同文件角色时，阻断原模型最优性与复现结论。
- PCA/特征分解只允许对每个特征向量整列乘 `-1`，严禁逐元素取绝对值或逐元素翻号；核对载荷正交性、贡献率排序、所选列索引和得分矩阵维度。用构成综合指数的输入变量检验该指数时，只记内部一致性，不记独立验证。
- 最近中心/均值分类逐项核对正文距离公式与代码；平方差开方须检查定义域，绝对距离、欧氏距离和标准化距离不得混名。用同一组构造特征产生的评级或 PCA 趋势检验概率时，只记同源一致性，独立验证需另有标签、时段或外部损失。
- 逻辑掩码计数使用 `sum(mask)`、`nnz(mask)` 或等价计数；MATLAB 的 `length(mask)` 只返回向量长度，不代表真值个数。为每种状态建立可手算的最小计数测试。
- 正文中的多人状态若含玩家索引、他人位置或联合库存，附录状态结构和转移也必须包含这些维度；实现退化为单主体搜索时，摘要和结论同步降级表述。
- 资金与资源更新按动作建立会计恒等式测试：购入、双倍补给、挖矿收益和终点回收分别触发，核对正负号、倍率与时间消耗。栅格证据确认实现正确时，应撤回 OCR 或初读造成的假阳性。
- 建立参数血缘：正文估计的转移矩阵、稳态/预测概率、代码随机生成器和结果情景必须参数同源。代码另写概率常量或只生成一条路径时，阻断“模型仿真/稳健性”结论。
- 建立结果血缘：每个报告值能追溯到输入、状态更新、累计量与输出。发现 `x=x+...` 后短距离内又以无说明字面常量 `x=c` 覆盖，或脚本只读取预置状态/路径却声称执行动态规划、MDP 或博弈求解时，先阻断复现与最优性结论。
- 跨问题建立不可变数据谱系：上一问输出保存文件名、版本/哈希、对象数和字段，下一问显式加载并复核；只依赖工作区残留变量、默认路径或未注明版本的同名文件时，不能声称复用了上一问结果。
- 监督学习的每个报告指标标注数据角色：训练回代、内层交叉验证、验证集或最终独立测试。代码若在 `fit(X,y)` 后以同一 `X,y` 计算 Accuracy/AUC，结果只能标训练指标；不得在摘要改称预测准确率。
- 基线与改进模型共享同一实体/时间划分、预处理折和指标。不同切分、不同样本或不完整代码产生的数值不得直接计算“提升百分比”；同时区分相对增幅与百分点差。
- 时间预测至少保留上一期、简单均值或题面直接基线之一，并与复杂模型共享完全相同的滚动窗口。若复杂模型没有稳定改善全体样本和题目真正关心的子集，只能收缩进入、降为情景或撤回；不能用模型名称替代胜出证据。
- 类别平衡、重采样或代价敏感训练得到的概率若与滚动发生率不一致，先区分排序能力与概率口径，再用训练窗内或滚动窗的校准方法修正；未校准输出不得直接求事件期望数、风险总量或置信区间。
- 数据没有处理对象身份、介入时间、对照组或混杂控制字段时，异常残差只能称候选跃升、能力缺口或外部核查名单，不得命名为教练、政策或措施的因果效应。
- 级联预测保存中间类别概率和误差传播协议。预测评级等硬标签作为下一模型特征时，至少做 oracle 标签、预测标签与概率输入三组对照；否则决策不确定性结论降级。
- 结果表逐行检查逻辑与域：决策标志为 0 时额度/流量等执行变量应为 0 或明确标为未采用候选值；数值不得越过正文/代码给出的上下界。发现冲突后回溯求解前边界、后处理和导出脚本。
- 启发式/随机优化为每个候选保存不可变 `solution_id` 或决策向量哈希；排序后的目标、导出的决策向量、表中策略和摘要最优值必须具有同一标识。再按最终展示变量独立重算目标与约束，防止用最优候选的目标配未排序候选的策略。
- 数据/代码的日期、实体、行业和样本范围须与正文用途一致。用 2017 年代码片段支撑 2020 年事件分析、用未说明的随机子样本代表总体，均不能作为可复现证据。
- 外部政策、地区案例或行业冲击比例进入全国/总体决策前，记录地区适用性、样本、时窗、统计或政策来源、置信/标定区间，并在区间内重求解；无来源的单点折减只能称假设情景，不能称稳健结论。

## 4. 写作门

- 摘要包含每问方法、关键结果和至少一项检验。
- 正文前先完成 [建模推演工作台](modeling-workbench.md)，并把其核心思考写回正文：每个非直接列式的首次模型前，读者至少已看见一个本题事实、局部数学关系、前问接口、试算或结果反推；其余解释按实际推导出现，不强制固定三步。反向检查和边界只在确有作用时记录，不能取代正文思考桥；初稿后运行 `audit_modeling_workbench.py`，再以正文中的局部证据接受公开判断账本检查。
- 25--30 页长稿在扩写每一问前，必须通过 [分问推演预审](reasoning-preflight.md)：队员用一页以内确认冻结来源、锚点、数学落点和选定路线，运行 `audit_reasoning_preflight.py` 后才允许扩写该问。来源、锚点或路线改变会使预审失效，必须回到短计划而非在长稿末尾大修。
- 正文起草前还必须运行 `prepare_style_retrieval_plan.py`，按章节绑定 3--8 个已核验全文段落和相邻上下文；再运行 `prepare_section_authoring_brief.py`，把每节的分问归属、本题事实、数学落点、路线和真人预审与语料 ID 绑定。发布前分别运行 `audit_style_retrieval_plan.py` 与 `audit_section_authoring_brief.py`，核对完整 TeX 树、59 篇语料索引、盲测保留排除、工作台、预审、章节目标和分问覆盖。检索材料只用于观察事实入口、判断动作和收束方式，不得复制句子或移植范文事实；工作台字段不得被翻成固定段式。
- 工作台中的题面、数据、代码和结果文件必须以相对路径与 SHA-256 冻结；正文稳定后运行 `audit_corpus_overlap.py --fail-on-overlap`，逐项裁决长字面量重合；人工选定稿件后，由两名队员逐问完成 [思考桥复述](reasoning-review.md) 并运行 `audit_reasoning_review.py`，只检查正文有无偏离预审路线。这些门分别约束源漂移、语料搬运和队员理解，不能单独证明文风自然或数学正确。
- 内部判断账本不得原样进入正文。连续出现“核心困难—基线—不足—候选—选择—改进”等标签，或各分问反复按同一顺序报账，视为机械推理框架；改为把局部判断放回触发它的数据、公式、边界、试算或结果附近。
- 思考过程只保留实际改变模型的判断。候选、失败尝试和舍弃理由必须有题面、数据、公式、图表、代码或同口径试算支持；为补全固定链条而虚构的“先考虑……后发现……”不通过写作门。
- 不要求每次选型都列多个模型。单一路线若由守恒关系、变量域、边界条件或数据形态直接决定，可以直接沿证据展开；真正存在竞争路线时再比较。是否“像人写”由局部因果和判断留痕决定，不由候选数量决定。
- 检查相邻段落的可见节奏：三个及以上段落使用相同段首或重复“首先—其次—最后”“考虑到—因此—故采用”“核心困难—故先—再”等句架时，须拆回具体对象并改变信息落点；不得仅做同义词替换。
- 定义修正先给共同量与可观察矛盾，方法切换先给旧方案的具体负担和新接口；初始搜索失败时写明失败位置、触发原因、局部修复范围及保持不变部分。只写“提高精度”“进一步优化”或“采用学习模型”不通过写作门。
- 数据侧写中的每张图须写明它支持的变量、窗口、候选范围或约束判断；与后文无接口的装饰性 EDA 不通过写作门。
- “代表性对象”须给排序量、阈值、所取位置和全量附件；回归系数须至少有一次业务单位解释；人工特征须给计算口径、代理语义和下游用途。
- 附件内已量化证据与待采外部数据分栏。外部数据建议至少写采集方式、可区分机制和支持动作；代理量有竞争解释时先列机制和追加证据，不直接贴经营标签。
- 数据病态触发换路时，段落须同时交代可观察病态、原方法受影响处、转换后的样本单位和新方法输入；不能只用“数据复杂”承接算法名。
- 模型阶数或窗口若由业务事实确定，须写明保鲜、交付、响应等实际时间尺度及其对应的滞后项；诊断表先解释行列与判据，再以具体范围给有限结论。
- 异常预测值须保留其诊断含义并译成余货、折价、不补货等业务状态；独立频数或规则路线只能说明它实际核对的候选层，不改称外部验证。
- 预测进入优化前，逐项写清单位、对象索引、损耗换算、计划进货、前日余货、新补货和陈列下界。正文保留裁决与关键数值，附录列完整后验、全量表、文件角色和代码入口。
- 开放任务不得用“多维度分析”代替选择：列出题目未指定项、互补观察面、每一面回答的问题及其进入后文的变量、窗口、候选或约束。统计机制必须能对应当前图的具体时点或对象。
- 候选模型切换须保留同源输入、指标、实际不足和新方法针对点；数据缺失、时窗太短、无明显趋势或近似随机时，允许降级为均值或规则，但必须说明复杂方法所需条件、当前不满足处和结论时窗。
- 求解器切换前比较变量域、目标数和约束结构；从连续 PSO 到 $0/1+$连续混合编码或多目标算法，须由新增结构而非算法新颖性授权。预测经弹性/响应关系修正时，保留基线量、修正量及其进入收入、成本、损耗和约束的位置。
- “提升”须给可比历史或基线：说明同季、同星期、同对象或同状态的选择理由、统计范围和单位。开放建议从当前模型不能区分的关系推出待采字段、采集方式和预定动作，不另列通用因素清单。
- 微扰、噪声注入或局部扫描只支持已声明输入、范围、固定量和输出指标内的稳定性观察；不得把小范围输出波动升级为跨场景鲁棒性。
- A016 类写作须把“物理顺序--选根”“最早事件--缩域”“越界--回退--误差”“固定量--不可优化”“改变项--跨区复用”和“局部齐次--整体缩放”中的适用动作写全。`因此`、`可以发现`、`同理` 或 `高精度求解` 若后面没有具体条件、对象和执行步骤，不通过写作门。
- A178 类写作须标明代理模型只交付哪一段区间、完整模型用什么判据裁决；粗搜和细搜分别写初始区间、步长、产物与停止精度。原参数多值时，换成时间/弧长单值参数必须说明旧约束负担；严格动作条件下若目标固定，先给否定结论，放宽条件时点名新增自由度并分情形。峰值段须按“接口机理--猜想--多工况只检验该结构--局部精搜”推进；验证须说明另一计算口径、同一输出、误差量和趋势原因。只写“近似提高效率”“放宽后更优”“结果稳健”或“验证良好”不通过写作门。
- A242 类写作须给出前问证据的具体去向：图形授权哪个首发对象，数值限定哪个上界，验证异常缩小哪个时间窗。缩域假设须有理由链和事后临界回查；搜索步长须由阈值接近或首次越界触发；外层参数与内层最坏量分开定义。算法比较须写候选、试算现象、函数形态和受阻机制；验证图须分别说明约束、收敛、空间或跨参数结构。齐次换算绑定同一位置，三分搜索前具备候选窗、粗扫结果和单峰证据。只写“沿用前文”“选择更优算法”“多角度验证”或“进一步缩小范围”不通过写作门。
- B159 类写作须说明两种业务态度是否改变 H0/H1，而不是只列两个置信度；样本量权衡同时给成本项、检验效果项和权重的偏好含义。离散方案须列决策变量、变量域和方案总数；代表方案压缩须给编号、分组依据、互斥事件以及其余公式/结果的完整去向。换成状态--决策模型前须写原方法在零件数、工序数或方案数上的具体负担；后问只替换不确定参数时须列冻结的决策集/成本结构和新积分接口。结果对照须写策略切换数、切换情形和价值差，先验扫描须限定策略、范围、固定量和输出。只写“分别建立假设检验”“枚举得到最优方案”“动态规划提高效率”“贝叶斯结果基本一致”或“灵敏度良好”不通过写作门。
- B195 类写作在无实测样本时须列仿真对象、生成分布、总体规模、次品判据和抽样规则；只写“模拟数据并验证”不通过。多阶段循环须有本轮输入、各阶段输出、拆后件/余量、下一轮初值和停止后果；理论上可省的检测与仿真中为统一接口采用的处理必须分开。删除或合并决策须点名重复步骤、原变量数、判定条件和保留变量数。连续比例落在 0/1 时要翻译为执行动作；两个候选方案须同时报告最终利润和收敛轮次，不能只以一个终值覆盖时间偏好。后验端点重算须写区间、固定结构、策略是否切换和利润变化；内部曲线不称外部验证，评价/改进节出现的算法名不视为已实现。
- B196 类写作在算法换路前须给决策节点、反馈环、路径/状态规模或实际计算负担；只写“问题复杂，采用遗传算法”不通过。跨问复用须列冻结的成本--收益/利润接口和被替换的搜索层。成本模型先给来源总数，每项写触发条件、计数量、单价和开关；图示不能表达的退换循环须文字补足。候选结果须给前十等范围、集中程度、主导规则、执行表和统一规模利润。随机算法须报告种群、代数、交叉/变异、精英、种子或重复协议；若只有一次曲线，只称内部收敛示例。`mu±3sigma` 结果须点名改变与不变节点，并用检测、拆解、调换和丢弃成本解释，不以“总体方向稳定”代替机制。
- B060 类光谱反演稿须通过八道门：预处理写明被压低噪声、被保留结构和连续表达式用途；局部极值法与全曲线法分别给输入范围、变量和输出；网格--高斯牛顿给变量尺度、范围、初值数、雅可比、更新和跨运行选择；高阶效应判据逐项解释物理因子；`G` 或同类量给当前取值及误差阈值；中间曲线差必须回代最终任务量；异常点同时有统计门、误差传播和物理位置依据；正文结果与附录物理/优化/统计接口对应。只写“平滑提高质量”“两种方法相互验证”“多光束模型更精确”“组合算法避免局部最优”或“异常值处理后更稳定”，均视为证据链未闭合。
- 问题分析解释选型而非罗列算法。
- 结果逐项解释，评价绑定具体机制和局限。
- 没有“显而易见”“效果很好”“大量实验”等无证据表述。
- A/B/C 文风与主导难点一致。
- “全局最优”“稳定”“精确”“验证通过”等强结论后紧跟证据类型和适用范围；限时启发式搜索只能报告当前最好可行解，除非另有界或穷尽证明。
- 搜索阶段和报告阶段若使用不同时间窗、尾窗、步长或状态初值，必须写明职责并在最终口径下复算；不能用短窗目标选择参数、再用长窗结果包装成同一最优性结论。离散事件造成末位跳变时，同时给相邻候选和触发对象。
- 两种策略的目标值相同，只能写该指标打平。只有决策向量、动作序列、状态转移和资源会计也按声明口径一致时，才可进一步称策略等价；故障产量损失也不得未经分解就等同于直接报废数。
- 多目标归一化交代上下界来源；若用有限随机样本极值作尺度，只称样本尺度估计，并报告样本量、种子和权重敏感性。
- 多目标方法明确选择词典序、约束法、加权法或 Pareto 法；若分层后再加权筛选，逐步说明偏好含义，并核对容差、归一化、权重、候选阈值在正文与代码中完全一致。
- 表头符号、单位和数值语义三方一致；同一最终向量在摘要、正文、候选表和附录中的有效位数统一。
- 有限网格只能支持“当前网格下的最大/最小可行样本”；若要称连续域最优，至少给首个不可行邻点、步长细化、单调性/界或精确求解证据。
- 拟合偏差即使恰好让某条约束更易满足，也不能写成模型合理性；必须分析偏差方向如何扩大或缩小可行域，并在修正或不确定边界后重新求解。
- 灵敏度分析声明每个扰动点采用“固定原策略复算”还是“重新优化”；同时报告目标变化、策略/路径切换、活跃约束与可行性。只有平移曲线而无重优化说明，不能支持策略稳健。
- 稳定性必须预先给出判据、可行域和失稳边界。“程序对每个参数都返回一个确定值”“曲线连续”或“数值变化平稳”只说明计算有输出，不自动支持模型/策略稳健。
- 确定性、随机性、多人三个层次应分别给基线：最短路/精确小实例、留出或压力情景、完整或扩大候选集。只以路线看起来合理、冲突较少或结果相近作为验证，不能证明最优性或模型正确。
- 结果文字明确标注“离线全知上界”“在线策略”“固定策略仿真”或“情景内重优化”；不同信息条件下数值接近不能证明在线策略最优。
- 博弈结论限定到实际分析的候选集、单阶段或局部状态；局部均衡不得无条件写成完整路径空间的全局均衡或多阶段子博弈精炼均衡。
- C 类结果段同时写数据划分、指标口径和策略可行性。社会效益、政策价值等定性结论若没有指标、权重、约束或反事实比较，应明确列为讨论，不写成模型输出。
- C 类集成结果将训练、内层验证与冻结外层测试分栏；同时报告多数类基线、少数类召回、宏平均、PR-AUC/校准及权重来源。接近满足预算的舍入表只能证明所示变量的残差，不能替代求解器状态、上下界或最优性证明。
- A 类几何结果区分“理想曲面候选”和“满足结构约束的可执行方案”；几何偏差或接收率改善若未同时给硬约束残差，只能报告候选性能。

- C063 类规划--风险稿须通过七道门：基期侧写确实限制变量或参数；求解器选择写出变量维数和线性/非线性结构；每轮灵敏度列明保持量与改变量；典型状态和统一环境集职责分开；风险准则由现实损失态度授权；状态表后给具体利润幅度与优先顺序；替代/互补最终进入面积或亩产变量。只写“采用鲁棒优化提高稳定性”或把不同状态数混作同一实验预算，均视为风险证据链未闭合。

## 5. 一致性与改写门

关键数学接口使用显式契约：

~~~bash
python scripts/audit_math_semantics.py main.tex \
  --contract math-contract.json --format text
~~~

契约应选取风险最高且能明确核对的符号、单位、目标方向、约束、代码变量和复算量，不必把所有公式机械抄入 JSON。`rechecks` 只使用实际输入和可独立复算的 `sum/mean/rmse/max_abs` 等量；契约通过不等于模型证明。

存在外部计算结果时，同时运行：

~~~bash
python scripts/audit_result_sync.py main.tex \
  --manifest result-manifest.json --format text
python scripts/audit_repro_manifest.py repro-manifest.json --format text
~~~

前者锁定正文关键字面量，后者锁定运行元数据和分析脚本、数据配置、结果及图表的哈希；两者不能互相替代。

中文学术改写只在证据稿稳定后执行一次，并读取 [single-pass-rewrite.md](single-pass-rewrite.md)。改写前后运行：

~~~bash
python scripts/audit_rewrite_contract.py before.tex after.tex \
  --terms protected-terms.txt --format text
~~~

公式、数字、单位、标题层级、TeX 命令、标签、引用、保护术语、最小化/最大化或不等式方向任一漂移时，改写稿不得覆盖证据稿。否定、因果标记和结论强度变化必须逐处人工裁决。不要连续调用多个降 AI Skill，也不要为了减少某个禁用词而删除数学限定。

## 6. LaTeX 门

python scripts/audit_manuscript.py main.tex --problem-type A --format text
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
~~~

当候选主文件与冻结编译资源分目录存放时，为每个实际资源树追加
`--resource-root <root>`。脚本会读取可解析的 `.bib` 并核对 citation key；该参数不能指向未冻结、
未参与最终编译的便利目录。

检查所有 error，并人工裁决 warning。逐问起止标签必须唯一、位于正文范围、顺序与覆盖清单一致且互不交叉或嵌套；否则逐问页数和密度统计无效。再扫描编译日志中的 undefined、missing、overfull、underfull、font warning 和乱码。图表具有 caption/label/引用，参考文献无未定义键。
