# 证据更新协议

## 目录

1. 适用范围
2. 记录格式
3. 核验流程
4. 结论等级
5. 冲突与撤回

## 1. 适用范围

用于把新获奖论文、赛题或专家评述增量纳入本 Skill。不得直接改写稳定规则而不留下来源和日期。

## 2. 记录格式

每条记录包含唯一证据编号、来源角色、年份/题型/论文编号、页码/章节/行或区域、短摘录或结构特征、确认状态、允许支持的结论、适用范围、核验日期以及被替代记录。

来源角色只允许 awarded_paper、problem_statement 或 expert_commentary。确认状态区分文本层、OCR、未确认 OCR 和视觉核验。

## 3. 核验流程

1. 固定文件哈希、页数和来源角色。
2. 提取文本；低置信页回退 OCR。
3. 公式、表格、图注用局部原始栅格核验。
4. 先记录单篇观察，不立即提升为通则。
5. 至少跨多篇或多年份出现后再统计为题型倾向。
6. 更新 references 后运行 Skill 验证和审计正反用例。

## 4. 结论等级

- 稳定规则：来自竞赛规范或跨语料高频结构。
- 题型倾向：在 A/B/C 某类中重复出现，但允许反例。
- 单篇观察：只描述来源论文，不外推。
- 未确认：OCR 或页面证据不足，不进入写作硬约束。

## 5. 冲突与撤回

新证据与旧规则冲突时并列记录适用条件，不用“最新”自动覆盖。若定位错误、OCR 错字或统计口径错误，保留撤回记录和原因；重算相关统计、模板篇幅和质量门。
