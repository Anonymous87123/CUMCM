# 59 篇论文语言模式图谱

## 1. 证据状态

本图谱覆盖 2020--2025 年 A/B/C 题 59/59 篇编号论文、2892 页，A/B/C
分别为 20/19/20 篇。每篇均有独立 `STYLE-01` 证据编号、论文卡、原页位置
和适用边界。全部论文均有页级判断轨迹；早期补录的 15 篇进一步完成了词语功能、
句间节奏、公式/图表接口和停止位置的统一字段。页级记录支持逐篇调用，不等于 59 篇
全文词频统计或逐句转录。

这里学习的是作者怎样把已经完成的建模工作组织成正文：从哪里起笔，方法名何时
出现，哪个证据使路线发生变化，图表后为什么继续写或停止，以及结论保留到什么
强度。不得把这些观察改写成统一的“困难--基线--不足--候选--选择--验证”段序。

逐篇索引见 [style-pass2-all-papers.md](style-pass2-all-papers.md)，原页证据见
[human-style.md](human-style.md)，模型与章节接口见 [paper-cards](paper-cards/)。

## 2. 人类论文并非一种语气

59 篇中反复出现的是证据进入正文的方式，而不是固定句式。常见起点包括：

- 题面关系或方程已经给出数学入口，正文直接定义或推导，不补选型故事；
- 数据、散点、残差或图形先暴露结构，再决定口径、函数或候选范围；
- 现实后果先排除不可行动作，再把后果写成下界、硬约束或非对称损失；
- 同口径试算先显示超限、残差或局部失败，只修改受影响的模型部分；
- 变量数、状态数、路径规模或函数评估量先说明计算负担，再选择搜索层；
- 后问直接读取前问输出，只写冻结项、改变项和新增接口。

一篇论文可以使用多个起点，但一个局部段落通常只承担其中一种主要动作。没有真实
材料时不补写。模型名之前需要的是当前选择不可缺少的局部证据，不是每问一段完整
的研究故事。

## 3. 各章节的语言职责

### 摘要

压缩任务、实际模型链、关键输出和真正做过的检验。核心分问可以略长，沿用前问的
分问可以更短；不要强制一问一句同构句。方法名可较早出现，因为摘要承担交付而非
展开论证，但必须与正文实际模型和数值一致。

### 问题重述

朴素重组对象、已知、所求、限制和问间关系。这里通常不承担方法比较，也不需要用
意义、价值和挑战收束每一段。

### 问题分析

只交代本问确实需要的总方向。直接关系可以直接落到数学量；信息缺口、边界、数据
异常或前问接口才展开。具体选根、换求解器、回退或缩域通常留在公式、算法或结果
真正出现的位置。

### 模型假设

每条假设说明它删除了哪个自由度、改变了哪条方程或允许了哪一步近似。可由量级、
几何关系、业务后果或当前信息集授权；不把“便于计算”单独当成依据。

### 符号说明

表格承担重复定义，正文只补索引范围、单位、状态时点和容易混淆的量。新符号在首次
进入公式附近仍可局部解释，不要求把后文所有中间量提前塞入总表。

### 模型建立

定义与公式构成主干。文字解释关系来源、非显然近似、边界条件、多根筛选、变量域和
前后公式接口。推导可以直接连续进行；只有发生取舍或读者无法复算时才插入判断句。

### 求解过程

按实际程序顺序交代初始化、更新、可行化、越界处理、停止和输出。粗搜、缩步、回退、
修复或换路必须写出触发条件；直接调用确定性求解器时不扩写成一段算法百科。

### 结果分析

普通读数可以一句带过。优先展开异常区间、边界附近、活跃约束、方案切换、主导对象、
与预期不一致的现象及其下游影响。原因必须回到轨迹、状态、成本、方程项或数据口径，
不以“符合实际”“验证有效”代替解释。

### 检验与灵敏度

直接写检查对象、固定量、扰动范围、比较口径和读数。守恒检查、回代、误差比较、交叉
验证、外部验证和随机重复不得互相冒充。局部步长加密只能支持当前离散结果，不能升级
为全面稳健性。

### 评价与改进

沿正文已经暴露的误差源、信息缺口或计算负担回看。已实现的修正用过去时，尚需数据
或新实验的改进用将来时；两条具体限制比统一的“精度、效率、适用性”三项评价更可信。

### 附录

按数据流排列输入、公共函数、主流程、结果导出和复现说明。正文写裁决与解释，附录写
全量坐标、日志和代码；两者使用同一变量、参数、阈值和结果版本。

## 4. 八类可迁移的段内推进

以下是检索类别，不是段落模板。正文只保留当前材料实际发生的环节。

1. **直接推导**：已知关系或性质进入定义，连续推到方程、边界或唯一未知量后停止。
   代表锚点：A217、A053、B030、B311。
2. **前问接口**：先列不变输入输出，再写缺失量、新目标或新约束；仅重建改变部分。
   代表锚点：A147、B125、C142、C305。
3. **失败触发局部修正**：给出残差、超限或失败对象，只修改对应参数、时间段或区域。
   代表锚点：A212、B477、C006、C126。
4. **现实后果转约束**：先写不可接受动作或损失，再落成下界、硬约束、分段损失或停止门。
   代表锚点：A053、B159、C063、C169。
5. **粗细搜索**：先用物理范围、单调性或代理模型定候选窗，再加密、二分或局部精搜。
   代表锚点：A022、A016、A178、A242。
6. **同口径候选裁决**：候选使用相同样本、指标、预算和约束比较，并明确舍弃理由。
   代表锚点：B007、B050、B086、C094。
7. **状态连续推进**：前一时刻或轮次的期末状态进入下一步，文字保持动作与状态更新顺序。
   代表锚点：B108、B195、C006、C094。
8. **结果反推原因**：从异常、突增、反转、局部误差或活跃约束回到轨迹、参数或机制。
   代表锚点：A053、B060、B196、C063。

## 5. 节奏和惯用词

人类作者常用 `由题意`、`注意到`、`不妨设`、`这时`、`仍需`、`只需`、`取`、
`令`、`记`、`由图可知`、`根据式（·）`。这些词不是风格装饰：后面必须分别接题面
关系、会改变求解的结构、不损失一般性的设定、状态变化、局部缺口、已经证明可消去
的部分、定义、图上读数或具体代入。

段落不要求同长。公式密集处可以短，异常解释可以长；有的段落直接从变量或图表起笔，
有的在一句局部判断后结束。若连续数段都以“针对……本文……”开头并以“说明模型有效”
结束，应先检查它们是否在重复同一功能，而不是轮换同义词。

## 6. 检索协议

起草正文前先描述当前段落的真实动作，然后检索 1--3 个锚点：

```powershell
python scripts/query_style_patterns.py --problem-type A --section analysis --action 缩域 --limit 3
python scripts/query_style_patterns.py --problem-type B --section solve --action state-progression --limit 3
python scripts/query_style_patterns.py --problem-type C --section result --query "异常 机制" --limit 3
python scripts/query_style_patterns.py --paper A053 --limit 1 --format json
```

检索结果给出单篇判断轨迹、拒绝的空写法、论文卡和证据行。完整读取选中的论文卡，
只迁移起点、转折、公式/图表接口和停止位置。一个小节选一个主锚点；确有另一种不同
功能时再加一个，不为每段随机更换范文。

正式更新语料后运行：

```powershell
python scripts/audit_style_corpus.py
```

只有索引、`STYLE-01` 证据、论文卡和 A/B/C 分布同时闭合时才通过。

## 7. 不得生成的伪思考过程

- 没有运行过基线，不写“实验发现传统方法效果不佳”。
- 没有比较候选，不写“综合比较后选择”。
- 题面关系直接决定方程时，不补“核心困难--候选算法--选择依据”。
- 事后看到结果才形成的解释，不伪装成事前选型理由。
- 不把内部检查账本逐项改写为正文句序。
- 不输出模型内部隐藏思维链；只写读者复算和判断结论范围所需的公开建模依据。

## 8. 篇幅边界

总页数与十四类章节跨度的实测中位数和四分位范围见
[paper-structure.md](paper-structure.md)。页数不是质量指标；新增篇幅优先放在变量口径、
推导接口、约束来源、异常解释和检验边界上，不放在背景扩写、算法百科和统一总结句上。
