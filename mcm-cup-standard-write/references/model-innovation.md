# 模型创新与方法边界

## 目录

1. 创新的判定
2. 基线到改进
3. A/B/C 切入点
4. 失败模式
5. 对照协议

## 1. 创新的判定

创新不是算法名称稀有，而是对题目中真实缺陷作出可验证修正。合格创新至少回答：基线遗漏什么机制、约束或数据结构；新增部分如何进入方程、目标或算法；付出什么复杂度和假设代价；用何种对照证明改进有效。

## 2. 基线到改进

- 先实现可复算基线，固定数据切分、评价指标和随机种子。
- 用残差、约束违背、敏感参数或极端情景定位缺陷。
- 每次只增加一类关键机制，保存消融结果。
- 若复杂模型不显著优于基线，保留基线并解释边界。
- 机理题可先以集总 ODE 建立低成本基线，再根据残差发生的时段、方向和形态提出边界过渡或分段参数；修正必须在留出工况上验证，不能用同一条标定曲线同时证明改进。

## 3. A/B/C 切入点

A 类可考虑非线性阻尼、时变边界、空间非均匀参数、耦合状态、几何精确性、参数反演和无量纲分析，并用网格/步长收敛、守恒和观测残差验证。几何拟合精度只有在固定长度、相邻节点距离、行程/力限值和结构兼容等题面硬约束仍成立时才构成有效改进；控制输入方向与节点状态位移方向必须通过结构关系连接。跨问题数据版本、随机样本协议和不确定性区间若可复核，也可作为验证层创新，而不是附录细节。

对波浪或受迫振动类 A 题，可把“受力平衡—一阶状态—RK4—稳定窗口—离散目标—粗略搜索—GA 精求—周期误差—参数扰动”作为分层接口。前期瞬态先决定统计窗口，粗搜只回答峰值和可行域，精细算法再回答参数定位；周期误差必须先定义零点/周期和阈值，惯量或测量扰动必须对应已说明的误差来源。该增量由 `EV-20260730-A001-01` 与 `EV-20260730-A001-STYLE-01` 触发，属于单篇可迁移链，不宣称 A 类论文的共同频率。
对波浪能装置类 A 题，还可把“平衡位高边界—前问数值授权—解析/数值切换—小量近似—单调上界”作为方法接口。先用平衡高度判断浸没边界，再由前一问的数值结果说明为何从复数解改用 `trapz` 或非惯性系小角近似；只有在图形支持单调时才把变量固定为上界，并对剩余参数做局部加密。创新在于每次方法切换都留下可观测授权，而不在于堆叠求解器名称。该增量由 `EV-20260730-A022-01` 触发，只作单篇可迁移方法路线。
对具有平衡、分段恢复力和耦合运动的 A 题，A171 又提供“边界—方程性质—方法—同口径结果—判定”的接口：先由平衡压缩量和吃水确定分段浮力适用域，常系数阻尼才进入拉普拉斯，幂律阻尼再改写一阶系统用 RK4；功率目标固定在最后十个稳定周期，解析解、数值解和垂荡--纵摇耦合沿用同一时刻表；最后用解析解对 RK4 做分阶段误差判定。创新在于把方法授权、结果对读和检验规则连成一条可追踪链，不在于同时罗列多个求解器。该增量由 `EV-20260730-A171-01` 与 `EV-20260730-A171-STYLE-01` 触发，只作单篇可迁移路线。

对定日镜场、反射阵列或空间采集类 A 题，可按“双坐标反射几何--五类效率--塔影中心判据--镜面网格无效点--锥形射线/接收体求交--全年代表时刻--效率云图选址--特征距离与分区同心圆--单位面积输出约束--粗细搜索--同口径策略比较--尺寸/塔高灵敏度”组织。创新接口不在算法数量，而在六处：题面已知量先被剔除，只计算剩余效率；工程简化由数量、对称和统计补偿授权；坐标变换最终落成可执行的内外判定；空间效率图直接改变塔址和布场变量；镜间硬距离通过特征直径连接内外区域排布规则；计算预算决定二分、大步长和小步长的分工。灵敏度同时写变化区间、方向非对称、饱和和分效率排序。该增量由 `EV-20260730-A0127-01` 触发；枚举结果不冒充连续全局最优，离散化近似须保留误差边界。

另一种空间光学创新接口可写成“几何子判定统一--物理传播链--近邻候选缩减--快速核误差门--空间图确定方向--固定变量逐项响应--单峰一维搜索--冻结继承变量--新自由度随机搜索--结构预言检验”。矩形先化为两个三角形，使遮挡、截断等区域判定共享同一可执行接口；六近邻把全场两两比较缩为局部候选；$2\times2$ 快速核只有在与高精度核同输入对照并报告偏差后才进入搜索。空间分布图负责确定塔位方向，固定其余变量的响应曲线负责说明何时可用三分搜索；后问沿用前问时冻结镜宽、塔距与镜面位置，只开放各圈高度。最后不靠空泛“误差较小”，而是预言峰值随太阳视运动迁移，改变采样时刻后检查图形结构。创新在这些接口和计算预算的衔接，不在三分搜索或蒙特卡洛名称本身。该增量由 `EV-20260730-A0165-01` 与 `EV-20260730-A0165-STYLE-01` 触发；不足 $2\%$ 仅是快速核分辨率检查，随机高度搜索也不是全局最优证书。

还可采用“条件分支光线核--距离邻接--规则几何骨架--分层抽样--弱变量冻结--阈值余量再优化”的接口。塔影、入射阴影、反射遮挡和集热器接收按短路顺序计算，每个分支说明成立后跳过哪些步骤；邻接矩阵由全对全规模与物理局部性共同授权。圆环蜂窝布局先产生可行位置骨架，整体旋转只保留一个方位变量；10%×10 的抽样只估计粗参数，30%×5 与更小步长承担后续评价。旋转角和安装高度经固定基线试算后若只在窄区间内改变目标，可以冻结并把预算转向镜宽和塔位。方案超过硬功率阈值时，不立即停止，而是分析删除高遮挡镜面对面积、总功率和单位面积输出的连锁作用，必要时改写为主目标加次目标或二目标。这一接口的创新在计算控制流和结果反馈，不在“蒙特卡洛”名称。该增量由 `EV-20260730-A0175-01` 与 `EV-20260730-A0175-STYLE-01` 触发；趋缓曲线只支持工作步长选择，抽样搜索只给候选或局部较优方案。

还可采用“直接量剥离--唯一随机量估计--双遮挡区域并集离散--序号曲线提出空间猜想--代表时刻二维图复核--双方向扰动与对称抵消--统一规格 GA--前问同心圆结构--按圈共享参数--变步长遍历--有限可行集背景比较”的接口。创新不在蒙特卡洛或 GA 名称，而在五个授权点：直接代入后只把唯一剩余概率量交给随机估计；重叠导致重复计数才触发并集离散；一维曲线只提出猜想，代表截面负责复核；方向对称与跨时段抵消才允许冻结坐标；前问规则结构与各向同性共同允许逐镜变量压为逐圈变量，并因此切换求解器。随机 100 组可行方案只能说明候选在该样本背景中占优。该增量由 `EV-20260730-A092-01` 与 `EV-20260730-A092-STYLE-01` 触发；网格与 10,000 次抽样均保留近似边界。

对链式刚体、机器人臂、蛇形结构或路径碰撞类 A 题，还可采用“起点状态--相邻定长递推--物理顺序选根--首发事件对象缩域--矩形/距离判定--内外层回退搜索--固定量证明--分区状态复用--齐次速度缩放--同输出灵敏度”的接口。创新不在再加入元启发式，而在六个授权点：数学多根由物理次序裁决；全对象碰撞由最早事件机制压缩；搜索精度由回退和误差界说明；题设优化目标若在约束下固定就如实证明不可优化；跨区域复用公开改变项；整体缩放有局部齐次传递作为依据。该增量由 `EV-20260731-A016-01` 与 `EV-20260731-A016-STYLE-01` 触发；论文报告数值未独立复算，固定弧长结论只限原几何约束。

同类链式运动题还可采用“低成本代理缩域--完整几何裁决--粗细搜索分工--多值参数改为单值时间--严格动作下固定量证明--放宽动作释放自由度--接口曲率提出峰值猜想--多工况有限印证--局部求值--异口径检验”的接口。代理模型只有在明确交付时间上界或候选区间、并由完整判据接管最终裁决时才构成计算创新；放宽约束也只有点明新增的调头起点、半径或状态变量后，才说明为什么原先固定的目标重新可调。结构猜想先由曲率、切向或边界变化提出，多工况只检查声明的结构；最终检验另用近似模型或差分口径计算同一输出，并把误差趋势接回近似条件。该增量由 `EV-20260731-A178-01` 与 `EV-20260731-A178-STYLE-01` 触发；离散缩步不称连续全局最优，多速度位置检查不称全参数灵敏度。

还可采用“前问观察授权缩域--临界图回查--物理下界/前问上界夹定参数域--外层参数/内层最坏量--函数形态触发求解器换路--多角色验证--固定量几何证明--验证异常交付后问--齐次目标变换--候选窗/粗扫/单峰搜索”的接口。创新在证据复用和方法授权：上一问的图、数值和边界必须变成下一问的具体集合、区间或状态；SA/PSO 等选择由实际试算和目标函数地形触发；约束、收敛、空间状态和跨参数曲线各检查不同断言；验证阶段发现的局部异常可以成为下一问的输入。三分搜索只有在物理候选窗、粗扫和单峰图闭合后才成立。该增量由 `EV-20260731-A242-01` 与 `EV-20260731-A242-STYLE-01` 触发；有限 PSO 与局部三分不构成全局最优证书。

对视线遮挡、运动云团和多平台协同类 A 题，可采用“布尔状态--时间积分--连续区间证明--凸性缩域--理论误差与输出敏感性--多起点局部搜索--同口径算法对照--预测拦截点近似--完整判定微调--任务收益分层”的接口。创新不在同时出现二分、PSO、DE、网格和整数规划，而在每次降维都有中间对象和接管关系：布尔函数省掉区间枚举；一次进入/退出才授权二分；截面圆盘的凸性把圆柱表面缩到上下圆周；理论面积误差和最终时长平台共同选择采样量；预测拦截点重合只生成高质量起点，完整圆柱判定仍负责最终目标；飞行时间挤占云团寿命形成可解释任务收益，再进入整数分配和子问题。算法对照要继续读共同参数结构和物理路径，而不以数值接近结束。该增量由 `EV-20260801-A196-01` 与 `EV-20260801-A196-STYLE-01` 触发；PDF 未印出附件源码，当前内部比较不构成外部验证、附件复现或连续全局最优证书。

B 类可考虑不确定参数、机会/鲁棒约束、分阶段决策、滚动优化、可行性修复、代理模型和 Pareto 偏好，并用下界/松弛、精确小规模实例、多次独立运行和情景压力测试验证。

对“已有实验分析--条件优化--追加实验”型 B 题，创新可来自信息接口而非新算法名：先以受控条件分组和可解释回归建立基线；若目标由多个响应共同决定，直接建立目标量回归；若主效应遗漏领域上合理的联动，用方差分析、嵌套模型或交互消融选择交互项；再把回归系数或敏感度用于下一轮试验的因素筛选。试验设计必须受次数预算和安全/实施约束，危险组合修正后应说明设计性质是否改变，并把前问最优点、边界点或高不确定性点作为不同候选比较。该路线由 `EV-20260730-B007-01` 触发。

另一类实验创新来自“信息缺口的精确配对”。先把前文未闭合的问题列成清单，例如优化点尚未复核、理论最优组合在附件中缺测、峰值可能落在未采样时间段、材料差异与装料方式差异混杂；再为每个问题单独指定保持量、改变量、观测量和裁决规则。这样，五次实验不是五个参数点，而是五个不同的信息增益动作。模型选型也按同一逻辑推进：散点给形态，机理或上界限制外推，二者共同决定 Logistic、分段式或区间曲线。该路线由 `EV-20260730-B026-01` 触发。

第三类创新来自“让每一次取舍留下数值接口”。少量样本上比较三/四次多项式时，先用样本数和自由度识别 `R^2=1` 只是插值；递进回归把初始、非线性变换、交互项和标准化的作用拆开，每层用调整后 R 方裁决是否继续；从回归乘积的非线性规划切换到 BP 时，先说明局部解和实际偏差，再让新方法直接学习目标量。试验层又把 5 次预算拆为 3 次峰值探索和 2 次预测确认，并用模型权重固定影响较小的因素。创新不在“回归 + 神经网络”堆叠，而在拟合、解释、优化和实验之间都有可追踪的选择。该路线由 `EV-20260730-B050-01` 触发。

第四类创新来自“让粗粒度分析和精细模型各回答一个问题”。先用控制变量给出带组别和双响应读数的定性证据，再用不含交互的正交极差排序主效应，随后以含交互的标准化二次回归处理因素耦合。初始回归若暴露多重共线性，诊断图直接触发逐步回归；修正结果按 R/R 方、RMSE、F/p 三层解释。目标量另建普通回归并分约束情形优化，补充实验再分别检查曲线外推、缺失温区、两类响应的水平组合和优化点。创新不在把控制变量、正交与回归并列，而在“定性识别--无交互排序--有交互估计--诊断修正--目标优化--分角色补测”的信息接口。该路线由 `EV-20260730-B160-01` 触发。

对同时包含“已知/未知信息、单人/多人”的 B 题，可先构造四象限任务矩阵，再共享同一状态转移内核：确定性单人用最短路、动态规划或 MILP 给基线；未知信息用场景树、滚动时域、机会约束或鲁棒优化表达缺货风险；多人层把联合状态、拥塞/合作效用和信息可见性显式加入。四个象限必须共享题面会计规则，但求解结论和验证证据分开报告。

C 类可考虑分组异质性、时间漂移、缺失机制、代价敏感分类、可解释特征、校准、集成与预测—决策耦合，并用冻结外层测试、嵌套交叉验证、时间外推、消融、PR-AUC、校准曲线和误判成本验证。集成权重只能在内层学习，外层测试只作一次最终裁决。

C 类供应链/动态决策的创新也可来自信息接口，而不是增加算法名。先把稳定性、连续性等潜变量拆成带方向和时间窗的可观测代理，以客观赋权与评价缩小候选范围；再说明为什么历史均值会同时抹平周期位置和业务周期，改用同周次能力与误差模型。逐周决策保留“期初状态--订购--实际供货--消耗--期末状态”，供应商筛选、订购优化和转运规则分别承担不同输出。若初始结果没有表现出预期材料偏好，先由成本尺度和等产能关系诊断，再局部调整 A/C 结构；结果用全周期与代表周次互补解释，并以最大/平均降幅如实界定有限改善。跨问模型只有在输入、输出和目标不变时直接沿用。这条“潜变量代理--评价筛选--周期能力/误差--动态状态--求解角色分离--结果触发结构修正--接口沿用”路线由 `EV-20260730-C006-01` 触发。

另一条 C 类供应链路线从“局部失败”而非算法新颖度出发。四项指标先完成统计定义、方向和业务能力解释，两条稳定性规则共同确定期望供货口径；供应商初选后，固定周权重若出现总体达标而个别周缺货，便按当前缺口重赋权。连续低谷的长度给出前视库存窗口。订购与转运不强行耦合成一个黑箱：先写上、下层目标，再由离散贪心、大项预拆、0--1 背包与残项补救按接口接力；产能上界则把“总缺口为零”作为二分可行判据。效果评价发现历史与规划方案产能不同后，改用成本/产能统一分母，灵敏度再分别比较提前、延后和双向窗口。这条“指标解释--规则筛样--动态权重--数据定窗--分阶段目标--组合求解--同口径评价--窗口灵敏度”路线由 `EV-20260730-C085-01` 触发。

第三条 C 类供应链路线把创新放在“决策前提能够被事实修正”上。先把九项指标写到原字段操作、零值处理、方向和业务用途；熵权出现与经营事实冲突的排序后，才按绩效、战略和潜力作有限 AHP 修正并通过一致性门。供应商按稳态/周期分类，供货偏差和转运损失进入双目标；LP 的变量/约束接口和 DP 的状态空间边界共同说明为何改用外层选供应商、内层配转运商的双层贪心，达到两周库存后因额外采购、运输和库存代价而停止。订货式 A--D 在共同历史基准下比较可行性、成本、初期稳健性和机制含义，随机运行只保留高频较优的典型代表。材料方向权重给出过小/过大的双边界；扩产问目标逆转后把候选由 50 家重开至 176 家，并以动态/静态产能及三周时滞解释结果。这条“指标操作--权重异常--有限修正--随机双目标--双层贪心停止--候选机制裁决--随机代表--方向替换--目标逆转扩围--动态产能”路线由 `EV-20260730-C283-01` 触发。

农业种植优化可按‘基础利润模型—不确定性场景—尾部风险—关系结构—联合约束—稳健性复核’逐层推进。像 C038 那样，创新不只是把 CVaR、差分进化或遗传操作并列，而是把侧写图读数写进变量与约束，将正负相关分别翻译成互补和替代关系，再用共同不利情景与单因素微扰区分整体抗压能力和局部敏感来源。风险模型必须同时报告情景数、置信水平、尾部损失口径及为稳健性付出的利润让步；样本量较小时，应先检查方法前提，再说明为何从参数相关转向秩相关。

农业风险规划还可从“解释用状态”和“裁决用环境”分工切入。先由最优、最劣、均值和单因素端点组成少量典型状态，用来解释哪一类参数改变利润及决策顺序；再把同一批候选放入统一环境集交叉复算，以益损值矩阵裁决期望、乐观或最坏准则。若供给中断、粮食安全或民生保障使平均值不可接受，应先把该现实后果写清，再采用 max--min，而不是把“鲁棒优化”当作天然更高级的方法。替代和互补的增量也不在新造系数，而在把经济替代联到面积、把生态互补联到亩产，并用完整策略组合与旧基线同表比较。该路线由 `EV-20260731-C063-01` 触发。

另一种农业规划创新来自“管理语义可计算、启发式状态可回查、随机候选可公平裁决”。先把“不宜太分散”拆为单地块作物数上限与单作物分布地块数上限，并用收益--管理表选取参数；再把贪心写成豆类轮作门、动态性价比、销量阈值和跨年历史更新，而不是只给算法名。随机层先用情景形成候选，再把所有候选放入同一环境集复评，避免每个方案只在自己的随机样本上获胜。替代关系先过性质/用途/营养/耕作候选门和目标变化门，互补关系分别修改亩产与成本。创新点是这些接口和裁决顺序能够被正文、流程图与代码共同复核，而非新增一个更复杂的算法。该路线由 `EV-20260801-C094-01` 触发。

农业规划还可把创新放在“索引有证据、启发式始终可行、检验利用业务形态”。先用季次和地块两组对照表判断亩产、成本、售价分别需要哪些索引；再把复杂约束嵌入初始生成、交叉/变异后修复和最终检查。遗传算法增加早熟比例门与新基因注入，但其价值要由完整运行协议说明。结果验证除收敛曲线外，用轮作预言的隔年高利润结构和一个 2023 基线构造的保守方案检查利润尺度。风险扩展从华北灾害事实、季节和作物类别逐层落到亩产，跨问只替换变化接口。该路线由 `EV-20260801-C234-01` 触发。

## 4. 失败模式

- 把多个普通模型串联但没有信息接口。
- 用深度学习处理小样本，只报告训练拟合。
- 用智能优化替代可被精确求解的线性/整数模型。
- 以主观权重包装数据结论，却不做权重扰动。
- 在全量数据上标准化、降维和选特征后再交叉验证。
- 切分数据后仍对全体样本执行 `fit_transform`，或用包含外层测试的“综合准确率”学习投票权重，再把同一外层指标称为独立评估。
- 创建估计器后未执行 `fit`/载入模型就调用 `predict`，或使用库未识别的近似参数名而未检查参数字典与版本。
- 按样本行号硬造 0/1 标签，或在 Logistic 名义下调用普通线性回归；模型名称不能替代真实标签、二项损失和拟合接口。
- 强制每个对象的连续决策量大于正下界，却在结果表给出零值且没有准入二元变量；这不是舍入误差，而是模型可行域、代码和结果三方不一致。
- 正文目标、执行代码和结果表使用不同收益式或不同对象规模；三者未通过同一输入的复算前，不能把展示值称为原模型最优解。
- 逐元素把 PCA 载荷改成正数，或取载荷矩阵的前几行代替前几个主成分列，再把输入指标之一当外部效标验证综合指数。
- 手设概率函数却不检查 `[0,1]`，正文和代码使用不同系数/指数；主观冲击矩阵未说明赋值协议与归一化，仍直接驱动最优策略。
- 随机优化按目标排序后导出未排序种群的第一列，却把排序后的最优目标写在同一结果行，使“最优值”和“策略”不属于同一候选解。
- 只展示最好一次启发式运行。
- 用知名算法名包装不同的过程：例如把“爬山候选热启动、未计算状态预装优先队列、限时返回当前最好值”直接称为 A*，却不给 `g(n)`、`h(n)` 和最优性条件。
- 用有限随机样本的最大值代替目标真实上界做归一化，却不报告样本范围、种子和尺度稳定性。
- 灵敏度结果表与文字判断脱节，或只看正负号而不解释绝对量级。
- 先声称词典序优先级，随后又用当前候选集的 min--max 与加权和重排，却不解释偏好为何改变；这种混用会使最终解依赖候选样本与任意阈值。
- 把“多次运行并选择最好一次”写成稳健性。重复运行只有在报告可行率、分布统计、种子和停止条件时才构成随机算法稳定性证据。
- 把“残差方向让约束更容易满足”写成模型合理性；定向偏差会改变可行域，应作为风险传播而不是验证证据。
- 正文写局部模拟退火，代码却从全域独立重采样；或把接受转移数当成总迭代数。名称、候选机制、计算预算和横轴口径必须一致。
- 说“已调到同一数量级”却只实现 `0.1f_1+f_2`，不给尺度来源、权重语义和扰动结果；任意常数缩放不构成多目标创新。
- 把期望成本阈值当作完整随机策略，却不检查库存耗尽概率、尾部情景和信息到达后的再决策。只保留均值会掩盖风险，至少与分位数、CVaR、机会约束或滚动重优化之一比较。
- 先在少数人工候选路线构造支付矩阵，再把候选集均衡称为原问题均衡；或求得混合概率后直接选择最大概率路线。候选生成、覆盖误差和从随机策略到确定决策的接口都必须单独证明。
- 正文定义多人联合状态，求解和代码却退化成单主体最优路径。删去玩家维度不是近似细节，而是改变问题；必须显式改名、给近似条件并与真实多人小实例比较。
- 正文称 TOPSIS，代码却没有正负理想解、距离和贴近度，只输出熵权加权和；方法名称不能替代核心算子，指标列数、归一化循环边界和聚合公式必须逐项追踪。
- 把降序第 `k` 位称作第 `k` 百分位，或不说明选取高风险尾还是低风险尾；阈值创新须给排序方向、分位换算、样本量、并列值处理及对真实标签的验证。
- 把有序等级编码成连续数回归，以相关系数替代分类效果，且网络输出越出声明值域；应改用有序模型或明确切分规则，并报告逐类召回、宏平均与误判成本。
- 在 `PD\times LGD\times EAD` 中让 LGD 再含授信金额，导致金额平方进入损失；风险模型创新先通过单位与值域检查，再谈目标函数改进。
- 正文把 $Q$ 定义为风险增量并写 $(1+Q)$，代码却直接乘 $q$；公式、单位与实现的倍率语义不闭合时，情景重优化不能作为创新证据。
- 聚类后只展示一个 $k$ 与一组风险乘数/流失率，不检查标准化、距离、簇规模和参数扰动对决策切换的影响。
- 用参与构造风险概率的同一组特征、评级或 PCA 趋势反过来证明该概率有效，只能得到同源一致性；外部政策或冲击比例若无地区、样本、时窗和区间，也不能支持稳健情景结论。
- 只优化反射面/曲面的几何偏差，却省略固定拉索长度、相邻节点距离变化率或促动器边界；几何候选并不自动成为结构可执行方案。
- 把促动器沿径向运动直接等同于节点位移沿径向运动，而不写结构兼容与平衡关系；这会把控制输入和系统状态混为一谈。
- 声称最小化最大误差，代码却在候选最大误差中取 `max` 所在索引；极值方向必须用手算小例和最终索引同时核对。
- 用微调量递减或目标曲线趋平直接宣称全局最优；这类现象最多支持局部迭代趋稳，仍需下界、可穷举小实例、全局证书或多起点对照。
- 正文声明大样本、多次蒙特卡洛平均，代码却使用另一数量级样本或单次运行，且不报告种子、区间和样本量收敛。
- 后一问默认读取前一问结果，却不保存和核对不可变版本/哈希，导致工作区旧变量或过期文件参与求解。
- 硬约束已有超限结果，却用“多数节点满足”或通过率较高把候选写成可执行方案；硬约束不能由比例投票降级，除非题面允许且给出松弛代价。
- 把只提出或只推导的第二模型并列写成已求解创新，或在正文、表格和代码中对同一顶点使用相反符号；模型完成状态和坐标不变量未闭合时，方法数量不是贡献。
- 假设每块面板的反射信号全部覆盖接收面，再以投影面积比估计接收率；或直接乘无来源经验系数校准基准。这类代理若无光线追迹对照、标定集和误差边界，不构成物理性能创新。
- 在单参数扫描中固定其他决策、允许硬约束超限，只因每个输入都有一个确定输出就声称稳定；稳定性须绑定判据、可行性、固定/重求解协议和失稳点。

## 5. 对照协议

对每项改进保留同一输入、同一指标和同一计算预算。表格至少含基线、改进、目标/误差、约束违背、耗时和稳定性。结论只覆盖实际检验范围，不从局部样本外推普适性。

算法创新还应附“名称审计表”：状态、动作/转移、评价函数、数据结构、停止条件、随机性、最优性条件、复杂度逐项对应。无法填满决定性结构时，使用描述性名称，例如“限时最佳优先枚举”或“多起点局部搜索”，不要借算法名替代说明。该边界由 `EV-20260728-A147-01` 的实现核验触发。

分层多目标可以采用“上一层末代可行种群热启动下一层”的种群接力，但必须把第一目标容差写成工程阈值或经敏感性检验的参数，并与直接重启、加权和或 Pareto 前沿作对照。若再对候选归一化加权，应将其视为独立的偏好阶段，而不是继续声称纯词典序最优。该边界与可迁移做法由 `EV-20260728-A195-01` 触发。

集总 ODE 与厚度方向 PDE 不是按“简单/高级”二选一。先用 Biot 数、厚度温差上界、响应时间尺度和计算预算判定集总假设；若低阶模型残差呈稳定结构，再逐项加入分段时间常数或边界过渡，并保留原基线与留出验证。约束优化还应把最后可行/首个不可行样本、离散步长和正文--代码阈值对照作为模型链的一部分。该可迁移路线及其边界由 `EV-20260729-A212-01` 触发。

反射面等几何--结构 A 题应把“理想几何候选--结构兼容--硬约束回代--电磁/物理性能”分层验证；极值索引、RMS 定义、跨问题文件版本和蒙特卡洛预算各自保留最小可复核证据。单次启发式微调的步长缩小不能替代全局性证明。该边界由 `EV-20260729-A028-01` 触发，仅代表第五篇 A 类单篇观察。

当题面硬约束无法同时满足时，合格创新不是隐去超限，而是显式建立可行性诊断：先求硬约束可行解；若确认不可行，再用带物理含义的松弛变量或 epsilon-constraint 报告最大违约、通过率、空间分布和修复代价。偏轴几何用坐标不变量和节点标识消除符号/行序脆弱性；备选模型用“提出--推导--实现--求解--验证”状态表防止未完成方案共享结果。接收效率优先以入射、法向、反射、交点和覆盖构成光线追迹基线，面积代理只在与基线对照后用于加速，经验系数进入标定、区间和外推误差分析。灵敏度则同时给稳定判据与可行域，并区分固定方案复算和逐点重求解。该增量由 `EV-20260729-A115-01` 触发，仅代表第六篇 A 类单篇观察。

资源--路径类 B 题可把动作统一写成“耗时、库存变化、现金变化、可行条件”转移表，再按信息结构替换求解层，而不重复发明会计规则。未知天气的最低合格改进不是生成一条随机序列，而是校准情景生成器并做多次独立评估；多人层的最低合格改进不是增加“博弈”名称，而是明确效用、候选空间和联合状态。终点回收价值、全二维整数库存域、固定策略与重优化两种灵敏度口径应进入同一对照协议。该路线与边界由首篇人工核验 B 题 `EV-20260729-B078-01` 触发，目前只作单篇方法案例。

进一步的随机动态改进可保留“知道完整未来情景的动态规划解”作为离线全知上界，再构造只依赖当前信息集的非预见策略，并在留出情景上比较遗憾、失败率与尾部收益。若把现金作为同位置、同日、同库存状态下的价值并删除被支配状态，须证明现金对后续可行性和目标单调，且终点残值已进入价值函数。博弈层按最佳反应、支配关系、纯均衡、内点混合解和边界解的顺序求解；跨日库存、位置与现金存在时保留联合状态，不用相互独立的每日矩阵替代多阶段策略。该路线由第二篇人工核验 B 题 `EV-20260729-B108-01` 触发；这一证据步只依赖 B078、B108 两个单篇案例，仍不作频率结论。
