# 课程笔记改写范式

## 使用方法

先识别句子或段落承担的教学功能，再选择范式。范式不是固定模板：只复制结构关系，不复制口头禅。每次改写后核对事实、符号、定义域、题目身份和结论强度。

## PAT-NOTE-01 论文式贡献改为学习目标

**触发**：`本文创新性地构建...具有重要理论意义` 出现在课程笔记。

**操作**：研究贡献 -> 学习对象 + 可完成动作 + 前置条件。

**前**：`本章创新性地构建了圆锥曲线切线问题的完整理论体系。`

**后**：`本章练习两件事：由切点写切线，以及从动直线的参数式判断候选包络。第二部分需要先会消元和判别式。`

**护栏**：若文本真在介绍历史性定理贡献，不要删掉事实；改掉的是作者自我抬升。

**规则**：`NOTE-TEACH-01`、`NOTE-STYLE-03`。

## PAT-NOTE-02 空洞路线前言改为关键观察

**触发**：每题先写统一的“总体策略、主路、底座”。

**操作**：删掉通用路线，保留本题独有的识别线索。

**前**：`本题仍沿用统一主路，先锁定入口，再把问题送回母式。`

**后**：`两条切线共享同一外点，所以先把两条切线方程都写成关于该点的极线关系。`

**护栏**：复杂章节可以保留一张章级路线图，但例题不重复。

**规则**：`NOTE-TEACH-02`、`NOTE-STYLE-05`。

## PAT-NOTE-03 均匀代数旁白改为“关键式 + 压缩计算”

**触发**：每次展开、移项、合并都配同强度解释。

**操作**：解释决定式；把可逆展开合并成一组等号或附录。

**前**：`先展开第一项。再展开第二项。然后合并同类项。最后移项。`

**后**：`关键是让含参数的一次项消失。展开并合并同类项后得到式 (4)，其中系数条件正好给出 ...。`

**护栏**：基础读者若可能卡在一次具体展开，保留那个中间式，不要一律压缩。

**规则**：`NOTE-TEACH-03`、`NOTE-MATH-04`。

## PAT-NOTE-04 “显然/易得”改为最小充分桥梁

**触发**：结论依赖被 `显然、不难、继续检查` 跳过的式子。

**操作**：补一个关键等式、定理条件或符号判断。

**前**：`继续检查可知 H(t)>0。`

**后**：`由式 (6)，H'(t) 在 [a,b] 上不小于 0，且 H(a)>0，因此 H(t)>0 在该区间成立。`

**护栏**：只补足当前结论；不要把所有算术事实都写成长证明。

**规则**：`NOTE-MATH-04`、`NOTE-MATH-05`。

## PAT-NOTE-05 局部展开降级为局部结论

**触发**：有限阶泰勒展开推出整个区间符号。

**操作**：中心/余项/邻域 -> 局部结论；若要全局，分区补证。

**前**：`由零点处展开可知，对所有 t>0 都有 H(t)>0。`

**后**：`该展开只控制 t=0 附近。若余项在 0<t<=delta 内满足给定界，可得此邻域内 H(t)>0；t>delta 仍需另证。`

**护栏**：不要为了保留原结论伪造 `delta` 或余项界。

**规则**：`NOTE-MATH-07`。

## PAT-NOTE-06 消元结论改为候选与回代

**触发**：`消去参数得 G=0，所以包络就是 G=0`。

**操作**：候选方程 -> 丢失/新增条件 -> 参数恢复 -> 结论强度。

**后**：`消元给出候选曲线 G=0。还需把各分支代回 F=F_s=0，并确认每个正则点能恢复合法参数；完成这些检查前，只能称为候选包络。`

**护栏**：若课程不要求完整包络证明，明确标“拓展检查”，不要假装已证。

**规则**：`NOTE-MATH-08`、`NOTE-MATH-09`。

## PAT-NOTE-07 自造术语翻译成标准对象

**触发**：`虚拟圆、母式、双变量系统、探针` 承担证明。

**操作**：助记名 -> 标准对象 -> 定义式 -> 域/常数 -> 双向关系。

**前**：`把变量送回虚拟圆即可得到结论。`

**后**：`令 (x(t),y(t)) 满足参数方程 (2)。由约束式可推出 (3)；反向恢复还需固定积分常数并单独处理零解。“虚拟圆”仅作为图形助记。`

**护栏**：没有标准翻译和双向关系时删除自造术语，不替它发明更多解释。

**规则**：`NOTE-STYLE-05`、`NOTE-MATH-08`。

## PAT-NOTE-08 绝对考试命令改为弱启发

**触发**：`铁律、永远、必选、锁死`，尤其来自小样本统计。

**操作**：样本观察 -> 使用时机 -> 反例/退出条件。

**前**：`出现这种位置关系时答案永远不相邻。`

**后**：`当前样本中这一位置关系较少与相邻答案同时出现，可作为复核顺序；若语义和指代证据支持相邻选项，应以原文证据为准。`

**护栏**：有正式语法规则时按规则强度表述，不要无故降成经验。

**规则**：`NOTE-TEACH-07`。

## PAT-NOTE-09 答案巧合改为精确法与策略法分层

**触发**：近似/选项排除得到正确答案，被写成一般推导。

**操作**：先精确依据，再写速度策略与误差。

**后**：`精确计算使用二项分布的阶乘矩。正态近似在这里给出同一选项，可作为数量级核对，但不构成该恒等式的证明。`

**护栏**：不要贬低考试策略；说明它验证或加速什么，而不是什么。

**规则**：`NOTE-MATH-13`、`NOTE-TEACH-07`。

## PAT-NOTE-10 对象漂移改为显式操作

**触发**：`f`、`f'`、原函数、插值多项式等无说明切换。

**操作**：命名当前对象 + 写出改变对象的操作 + 核对条件。

**后**：`上一行仍比较 f 的函数值。现在对等式两端关于 x 求导，因此从这一行起出现 f'；其存在性由假设 f in C^1 保证。`

**护栏**：不能用解释句合法化原本没有执行的求导；先修公式。

**规则**：`NOTE-MATH-01`、`NOTE-MATH-03`。

## PAT-NOTE-11 定理名改为本题条件检查

**触发**：`由罗尔定理/洛必达法则/泰勒公式显然...`。

**操作**：写当前区间、连续/可微/不定式等关键条件，再调用。

**后**：`函数在 [a,b] 连续、在 (a,b) 可导，且两端函数值相等，因此罗尔定理给出 xi in (a,b) 使 f'(xi)=0。`

**护栏**：无需抄完整历史说明；只写本题合法性所需条件。

**规则**：`NOTE-MATH-05`。

## PAT-NOTE-12 取对数全域式改为分支式

**触发**：除以未知函数并对整个区间写 `ln|f|=...+C`。

**操作**：零解 -> 非零连通分支 -> 分支常数 -> 拼接。

**后**：`在 {x:f(x)!=0} 的每个连通分支 I_j 上，积分得 ln|f(x)|=g(x)+C_j。零点和零解需代回原方程另行检查。`

**护栏**：绝对值不覆盖零点；不能自动令所有 `C_j` 相等。

**规则**：`NOTE-MATH-10`、`NOTE-MATH-11`。

## PAT-NOTE-13 渐近口号改为阈值证明

**触发**：`指数增长快于多项式，所以从 n=n0 起成立`。

**操作**：有限初值 + 阈值 + 保持机制。

**后**：`直接计算 n0<=n<N。对 n>=N，左右两侧比值单调下降，且在 N 处小于 1，因此不等式从 N 起保持。`

**护栏**：没有算出/证明阈值时只能写“充分大时”。

**规则**：`NOTE-MATH-12`。

## PAT-NOTE-14 目录式小结改为迁移小结

**触发**：`本节介绍了定义、性质、例题和应用`。

**操作**：识别信号 + 核心动作 + 失效条件 + 自检。

**后**：`看到分式求导后出现公共零点，先不要约分；把零点单列，再在非零区间化简。最快自检是把被约掉的零点代回原式。`

**护栏**：短知识点没有迁移信息时可以不写小结。

**规则**：`NOTE-TEACH-05`。

## PAT-NOTE-15 伪课堂互动改为可回答自检

**触发**：`聪明的同学一定已经发现、大家不难看出`。

**操作**：去掉对读者的评价，留下具体检查问题。

**前**：`聪明的同学已经发现这里必须取正支。`

**后**：`这里为什么取正支？因为参数表示长度，题设给出 r>0；若参数允许有向量，分支选择需重新说明。`

**护栏**：问题必须服务推理，不连续堆反问。

**规则**：`NOTE-TEACH-08`、`NOTE-MATH-11`。

## PAT-NOTE-16 质量管理状态改为具体检查结果

**触发**：`全面覆盖、已闭环、放行、全部验证`。

**操作**：对象/属性 + 方法 + 结果 + 未检查属性。

**前**：`全章已闭环并通过验证。`

**后**：`本章 42 个公式标签已解析，TeX 构建通过；抽查了例 1-5 的代数步骤。其余习题的答案来源和数学正确性尚未核对。`

**护栏**：不要为了显得谨慎虚构抽查数量或方法。

**规则**：`NOTE-QA-01`、`NOTE-STYLE-03`。

## PAT-NOTE-17 OCR 原文与解释分层

**触发**：转录句子看起来不通顺，模型想直接润色。

**操作**：原样层保留 + 不确定标记 + 解释层给候选理解。

**后**：

```text
[OCR 原文，第 3 页第 7 行] ...
[不确定] 第二个上标无法辨认，可能为 2 或 z。
[讲解] 若上标为 2，则该式可按平方差分解；需回看原图确认。
```

**护栏**：讲解不能反向覆盖原文层。

**规则**：`NOTE-PROV-02`。

## PAT-NOTE-18 新章节完成改为集成状态表

**触发**：章节独立生成后宣布“教材更新完成”。

**操作**：独立状态、主入口、前置知识、定义、编号、答案、全书构建分别记录。

**后**：

```text
章节正文：完成
主入口纳入：PASS
前置定义：PASS（见 2.3 节）
公式/习题标签：PASS
答案链接：FAIL（例 7 缺失）
全书编译：NOT RUN
数学复核：NOT RUN
```

**护栏**：不能从独立编译推断全书状态。

**规则**：`NOTE-DOC-01`、`NOTE-DOC-02`、`NOTE-QA-01`。
