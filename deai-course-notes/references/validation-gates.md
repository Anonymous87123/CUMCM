# 课程笔记验证门

## 目录

- 门 0：任务契约
- 门 1：来源与 OCR
- 门 2：事实、符号与题答对应
- 门 3：数学推导
- 门 4：教学结构
- 门 5：语言与节奏
- 门 6：教材集成
- 门 7：机械完整性
- 模式验收
- 可复用表格

每个门只验证其命名属性。`PASS` 必须有证据；未执行写 `NOT RUN`。不得由编译、禁词、转录或覆盖率推断数学正确。

## 门 0：任务契约

### 必填

| 字段 | 内容 |
|---|---|
| 文档类型 | 笔记/教材/例题/答案/错题/CET6/OCR |
| 读者 | 年级、课程阶段、已知前置知识 |
| 目标 | 理解/复现/训练/复习/转录 |
| 模式 | Audit/Rewrite/Generate |
| 权威入口 | 文件或明确“仅局部片段” |
| 允许改写 | 哪些段落身份可改 |
| 必须保持 | 题干、公式、标签、引用、答案等 |

### 失败条件

- 把建模/期刊论文按课程笔记放松；
- 未知来源却承诺“官方/原版”；
- 未知读者层级却任意省略关键步骤；
- 未经授权改写 source/OCR 层。

## 门 1：来源与 OCR

### 来源表

| 段落/页 | 身份 | 来源定位 | 置信度 | 可否改写 | 备注 |
|---|---|---|---|---|---|

### 检查项

- 每段属于 `SOURCE/OCR/OFFICIAL/RECON/EXPLAIN/NOTE/AUDIT`；
- 题干、引用、词典和教材原文没有被算作模型文风；
- OCR 不确定字符带页码/位置；
- 邻近文字没有冒充精确引文；
- 官方答案有权威定位；
- 重建答案明确挂牌；
- 乱码段跳过并记录，不据此猜测结论。

### PASS 标准

每个被改写段均有明确身份和授权；每个“官方/原文”声明均可定位。无法定位则必须降级措辞。

## 门 2：事实、符号与题答对应

### 事实锁

锁定：题设条件、数值、单位、定义域、变量、图号、选项、最终答案、公式标签、引用和已知勘误。

### 对象账本

| 符号 | 定义 | 类型/阶数 | 定义域 | 依赖 | 允许操作 | 冲突 |
|---|---|---|---|---|---|---|

### 题答表

| 题目 ID | 条件版本 | 选项/目标 | 答案身份 | 解答位置 | 最终值 | 回代 |
|---|---|---|---|---|---|---|

### 失败条件

- 题设改变但旧答案仍在；
- `f/F/f'`、点/向量、原函数/插值式换身份；
- 单位、下标、指数或正负号漂移；
- 重建解答标官方；
- 结论与中间式不一致。

## 门 3：数学推导

### 3.1 逐步合法性

对每个决定性步骤记录：

| 步 | 前式 | 操作 | 所需条件 | 方向 | 丢失/新增 | 回代结果 |
|---|---|---|---|---|---|---|

只有同一条件下双向成立才写 `等价`。

### 3.2 定理调用

| 定理 | 使用位置 | 当前对象 | 定义域 | 连续/可微/非零等条件 | 已验证 |
|---|---|---|---|---|---|

重点查泰勒、罗尔/中值、洛必达、反函数、隐函数、极值判据和包络条件。

### 3.3 局部到全局

全域符号、唯一性、完整轨迹必须列覆盖表：

| 区间/参数段 | 使用证书 | 边界连接 | 未覆盖点 |
|---|---|---|---|

有限泰勒项、有限采样或三个特殊位置不能单独 PASS。

### 3.4 消元、包络与切触

检查：

- 原方程和参数域；
- 被除/约/平方的因子；
- 结果式的各分支；
- 候选回代；
- 合法参数恢复；
- 实点、非零梯度与梯度共线；
- 端点、奇点和退化情形。

缺少任一决定性项时用“候选/必要条件/包含于”，不得写精确包络。

### 3.5 零点、分支与方向

- 除法和对数前证明非零或分域；
- 零解独立检查；
- 每个连通分支可有独立常数；
- 开方、反三角和积分保留分支/方向；
- 乘除、平方、取对数后重查不等号与等价性。

### 3.6 近似和考试策略

- 精确公式存在时优先给精确法；
- 近似写假设、误差与用途；
- 选项排除不冒充一般证明；
- 小样本规律列分母、反例和退出条件。

### PASS 标准

结论所依赖的对象、步骤、条件和范围均被覆盖；最小合法值/简单函数/回代没有反例。课程层级允许把高级证明标为未展开，但不允许把它标成已证。

## 门 4：教学结构

### 章节地图

| 节 | 学习问题 | 关键动作 | 前置知识 | 例题功能 | 易错边界 | 去重动作 |
|---|---|---|---|---|---|---|

### 检查项

- 开头给学习目标，不伪造研究贡献；
- 首次出现的新对象有定义和最小例子；
- 关键观察出现在长计算前；
- 决定性步骤比可逆代数获得更多解释；
- 重复方法通过回指压缩；
- 正例、反例和练习各有明确功能；
- 小结提供识别、动作、边界或自检；
- 难度跳跃有真实前置桥梁；
- 教学提示有导航功能，不形成固定口头鼓点。

### 失败条件

- 每题套同一五段结构；
- 每个等号都旁白但关键步骤仍缺；
- 小结只是目录复读；
- 所有“为什么”被删，材料只剩公式转储；
- 同一路线在章、节、例题、答案四层重复。

## 门 5：语言与节奏

### 人工检查

- 主语优先是函数、参数、条件、图形、例题或学习动作；
- 导航词后有具体对象或原因；
- 句长和段长随难度变化；
- 不用论文贡献、质量管理或营销话术抬升；
- 不用游戏/戏剧比喻替代论证；
- 自造术语有标准定义和等价；
- `显然/易得` 没有承担关键证明；
- “铁律/永远”有真正普遍规则支撑；
- 读者没有被评价为聪明、粗心或“应该已经发现”。

### 黑名单检查的正确用法

扫描黑名单只能生成候选位置。逐处记录：

```text
字面命中 -> 真实技术含义/错位话术
-> 当前句功能 -> 是否有实质信息
-> 保留/改写/删除 -> 回归检查
```

零命中不 PASS；仍需人工读结构、教学功能和数学责任。

## 门 6：教材集成

### 仅在整章/教材任务运行

| 检查 | 所需证据 | 常见失败 |
|---|---|---|
| 主入口 | 权威 `main.tex`/目录纳入一次 | 章节存在但读者不可达 |
| 前置顺序 | 定义/定理在首次使用前 | 高级对象突然出现 |
| 定义所有权 | 唯一定义 + 交叉引用 | 每章重定义且不一致 |
| 难度连续 | 读者与桥接说明 | 从基础题跳到研究级证明 |
| 编号标签 | 节、公式、图、题、答案链接 | 本地编号残留 |
| 题答身份 | 官方/重建/生成明确 | 重建答案冒充官方 |
| 版本状态 | 旧章删除或标历史 | 两套冲突章节同时生效 |

### PASS 标准

独立文件、主入口、前置知识、引用与答案均一致；全书编译与数学审查仍分开声明。

## 门 7：机械完整性

### TeX/Markdown

- TeX 环境、括号、命令和数学定界符平衡；
- 标签、引用、目录、图表和答案链接解析；
- Markdown 标记没有漏入 TeX 正文；
- 表格总数、选项数、题号和单位一致；
- UTF-8 可读，无未说明乱码；
- 公式换行没有改变运算顺序；
- 用户要求时运行编译，否则写 `NOT RUN`。

机械门通过不推出数学、来源或教学门通过。

## 模式验收

### Audit

- 覆盖全文而非只搜词；
- 来源表、对象账本和严重级发现完整；
- Blocking 先于风格问题；
- 每个发现可定位、可复核、带规则 ID；
- 未运行项明确列出。

### Rewrite

- source/OCR/官方材料未越权改动；
- 数值、公式、条件、标签、引用和结论强度保持或经授权修正；
- 关键步骤更可见，常规步骤更紧凑；
- 变更账本解释删除、移动和数学修正；
- 所有受影响题答链接回归检查。

### Generate

- 自拟材料明确挂牌；
- 没有虚构教材、课堂、教师、引文或官方答案；
- 学习目标和读者层级明确；
- 所有定理、公式和答案经过独立核算；
- 不自动生成论文式创新/展望；
- 小结有迁移价值。

## 可复用表格

### 最终门声明

```text
Scene contract: PASS/FAIL
Provenance/OCR: PASS/FAIL/NOT RUN
Facts/notation/question-answer: PASS/FAIL
Mathematics: PASS/FAIL/NOT RUN
Teaching structure: PASS/FAIL
Voice/rhythm: PASS/FAIL
Book integration: PASS/FAIL/NOT RUN
Mechanical integrity: PASS/FAIL/NOT RUN
Unresolved blockers: ...
```

### 变更账本

```markdown
| ID | 位置 | 规则 | 原功能 | 动作 | 数学/来源影响 | 回归检查 |
|---|---|---|---|---|---|---|
```

### 完成状态账本

```markdown
| 材料 | 已转录 | 已对原图 | 已编译 | 已核数学 | 已核答案来源 | 已优化教学 | 证据 |
|---|---|---|---|---|---|---|---|
```

只填 `PASS/FAIL/NOT RUN`；不得从左列推断右列。
