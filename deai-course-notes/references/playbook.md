# 课程笔记写作 Playbook

## 目录

- 总体声音

- 课堂推导与证明
- 例题与答案
- 错题复盘
- CET4/CET6 学习材料
- OCR 与转录材料
- 微积分笔记
- 圆锥曲线笔记
- 学习回顾
- 课程笔记黑名单

## 总体声音

目标声音是“自然、轻量、可靠的教师或认真复盘的学习者”：

- 直接指向当前对象，不先做宏大铺垫；
- 关键处解释理由，常规处允许压缩；
- 允许少量导航词，但不让导航词成为固定鼓点；
- 承认条件、分支和近似，不假装一步到位；
- 小结强调迁移和易错边界，不写成验收报告。

推荐节奏：短定位句与较长解释句交替；公式前说明用途，公式后解释它改变了什么。不要让每一段都有“策略—执行—验证—总结”四连结构。

## 章节与知识点笔记

### 开篇

优先回答三个问题：

1. 这一节处理什么对象？
2. 学完能做什么？
3. 需要哪些前置知识？

可用：

> 这一节只处理参数方程求导。关键不是背公式，而是先确认 `dx/dt` 是否为零，再把 `dy/dt` 与它相除。

避免：

> 本节构建了一套系统、完整且具有重要理论意义的方法体系。

### 主体

按概念依赖组织，而不是按固定模板组织。定义后尽快给最小例子；首次出现的易错条件在使用处提醒。多个方法比较时，按“识别信号—成本—失效条件”比较，不按“方法一/二/三各写等长小节”。

### 结尾

用三类信息收尾：何时识别、核心动作、何时失效。无需每章都加“未来展望”。

## 课堂推导与证明

先写证明主意，再进入代数。一个合格推导至少让读者看见：

- 当前对象及定义域；
- 为什么选这个辅助量/换元/定理；
- 哪一步真正推进结论；
- 哪些步骤仅为可逆整理；
- 条件和异常情形在哪里处理。

对于基础读者，可多给一个中间式；对于同一路线的第二题，用“与例 2 相同的消元”回指，不复制整段旁白。

## 例题与答案

### 题干区

原题保持原样；疑似 OCR 错误以注记提出，不直接修补。自拟题必须标“自拟”。

### 解答区

建议结构：

```text
识别线索（可选） -> 关键一步 -> 必要计算
-> 条件/分支 -> 结果 -> 快速检验（可选）
```

选择题可以介绍排除法，但要区分“快速得到选项”和“证明一般公式”。答案与选项巧合一致时，仍需核对方法是否一般有效。

### 答案身份

使用明确标签：`官方答案`、`重建解答`、`参考解法`、`独立核算`。没有来源定位就不要写“标准答案”。

## 错题复盘

不要抄完整正确解后写“粗心”。复盘四件事：

1. 当时在哪一步偏离；
2. 偏离属于对象、条件、符号、方法还是计算；
3. 下次最早能在哪个信号处发现；
4. 用一个最小检查验证修正。

自然示例：

> 错误发生在除以 `x-1` 时；题设没有排除 `x=1`。下次看到约因子，先把被约掉的零点单独代回原式。

## CET4/CET6 学习材料

把材料分为四层：语言事实、样本观察、考试启发式、个人复盘。它们的强度不同。

- 词义、搭配和语法规则要有词典/语料或原句依据；
- 小样本位置规律写明分母，不升级为“铁律”；
- 策略给出退出条件，例如语义冲突时停止依赖位置；
- 题型复盘具体到原文线索和干扰项机制；
- 不用“秒杀、锁死、必选、永远不相邻”代替理由。

推荐格式：

```text
观察：在本组 59 题中，模式 X 出现 9 次。
用途：语义证据不足时可提高检查优先级。
边界：样本较小，且出现反例 Y；不能作为排除规则。
```

## OCR 与转录材料

严格分层：

1. 原图定位；
2. 忠实转录；
3. 不确定字符清单；
4. 人工校订；
5. 生成讲解；
6. 完成状态。

转录层不做文风优化。讲解层可自然改写，但必须引用对应题目 ID。邻近页的相似句子只能帮助搜索，不能替代当前来源。TeX 编译通过只证明语法/构建状态。

## 微积分笔记

高风险点：

- 原函数、原函数的导数、插值多项式和余项换身份；
- 中值定理见证点被当作固定常数；
- 泰勒局部展开外推整个正半轴；
- `f'/f`、`ln|f|` 忽略零点与分支；
- 参数求导中指数符号错误；
- 洛必达没有核对不定式和邻域条件；
- “指数最终占优”跳过起始整数。

讲法：先说明当前函数和区间，再写定理为什么能用；用对象账本和最小反例辅助校验。不要用“继续求导即可”“反复检查可知”藏住核心符号证明。

## 圆锥曲线笔记

高风险点：

- 把仿射表达式写成双线性；
- 用三个特殊位置宣称完整轨迹或包络；
- 消元只写“整理得”，不列丢失因子；
- 由判别式为零直接宣称切触；
- 极点、极线、向量、齐次坐标在推导中换类型；
- 自造“母式、底座、虚拟圆”遮住标准定义。

讲法：图形直观可作为动机，代数和参数恢复负责证明。候选曲线与精确包络必须分开。重复路线只在章级给一次，例题突出本题特有的构造。

## 学习回顾

好的回顾可选用以下四格，不要求全部出现：

- **识别**：题目出现什么信号？
- **动作**：第一步做什么？
- **边界**：什么条件缺失时不能用？
- **自检**：最快的反例/代回/量纲检查是什么？

坏回顾只复述“本节讲了定义、性质、例题和应用”，或宣布“形成完整闭环”。

## 课程笔记黑名单

黑名单用于人工定位，不是机械零容忍词表。词语具有真实技术含义时保留；问题在于错位功能和高频模板化。

| 类别 | 高风险表达 | 问题 | 优先替换方向 |
|---|---|---|---|
| 伪科研 | `填补空白、创新性地、具有重要理论意义、研究贡献、外部有效性` | 把学习目标抬成论文贡献 | `本节要学会、用于判断、适合处理` |
| 质量管理 | `闭环、清零、放行、整改口径、验收完成、全量覆盖` | 把正文写成审核单 | 写具体检查对象与状态 |
| 游戏/战术 | `秒杀、锁死、翻盘、满仓、收割、死磨` | 用情绪替代方法边界 | `优先检查、可排除、回代验证` |
| 戏剧化 | `魔法、奇迹般、灰飞烟灭、宇宙级纯净、铁证如山` | 掩盖普通代数或证据不足 | 写发生的运算与结论 |
| 流水线 | `首先...其次...最后...综上` 高频重复 | 节奏由连接词而非内容驱动 | 直接写对象、条件和动作 |
| 空洞总括 | `系统全面、完整体系、深刻揭示、全面验证、充分说明` | 强度无对应证据 | 指明覆盖范围和未检查项 |
| 伪轻松 | `显然、易得、不难发现、继续检查可知` | 跳过决定性步骤 | 给关键中间式或定理条件 |
| 路线口头禅 | `入口、主路、底座、母式、送回、压回、收口、触发` | 同一路线在章/节/题多层复读 | 只在最高有用层保留一次 |
| 绝对策略 | `铁律、永远、必然、必选、绝不相邻` | 弱样本被升级为命令 | 样本量、适用条件、反例、退出规则 |
| 伪标准术语 | `双变量系统、虚拟圆、探针、算子、不变量` | 无定义时遮住对象错误 | 标准对象、公式、双向映射 |

### 黑名单验收

不得以“黑名单零命中”宣布完成。逐段回答：这句话承担什么教学功能？删去套话后是否仍有对象、动作、条件和依据？如果没有，需重建内容而非换同义词。
