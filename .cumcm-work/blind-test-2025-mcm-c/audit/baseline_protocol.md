# 同模型最小提示消融基线

## 目的

比较“只给题目、数据边界和最终计算结果”与“调用 `mcm-cup-standard-write` 的全文证据、推理展开和质量门”之间的稿件差异。基线不是另一模型，也不是严格意义上的认知隔离实验；主模型已经读过 Skill，因此这里只能检验检索与流程消融，不能检验模型参数层面的完全盲态。

## 基线输入

1. 2025 MCM Problem C 官方题面与四张数据表。
2. 数据审计事实：国家目标使用官方奖牌表；运动员表的团队项目存在重复获牌行；项目表本地附件止于 2024 年；2028 年基准沿用 2024 项目结构。
3. 已计算结果：
   - 总牌和金牌均采用东道主修正基线与随机森林等权组合；
   - 2008--2024 年滚动 MAE：总牌 1.441、金牌 0.627；
   - 美国 124.27/43.79，中国 88.47/38.86；
   - 首牌期望 5.08，90% 计数区间 2--9；
   - 项目边际情景与教练型跃升候选的最终表格。
4. 普通指令：“写一篇结构完整的中文数学建模论文，包含摘要、模型、结果、检验和评价。”

## 禁止给基线的内容

- 不查询 59 篇语料的原句、段落动作或章节证据。
- 不读取 `fulltext-language-usage.md`、`reasoning-before-model.md`、`human-drafting.md`。
- 不把 Skill 稿件作为改写底稿。

## 公平性边界

两篇稿件共用同一计算流水线、表格和图，因此比较对象是写作组织和证据接口，而不是模型精度。基线仍可能受模型已经读过 Skill 的残留影响，结果只按“同模型最小提示消融”报告。
