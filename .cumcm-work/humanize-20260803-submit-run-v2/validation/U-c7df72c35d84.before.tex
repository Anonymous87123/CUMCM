\subsection{模型评价与改进}
\begin{quote}\small
\noindent\textbf{\color{inkblue}写什么：}评价本模型能够回答的任务、计算和解释方面的长处，以及尚未纳入的因素和对应修改办法。\par
\noindent\textbf{\color{inkblue}怎么写：}优点回到公式、数据接口或检验结果；不足指出受影响的对象和边界。改进项写成“新增什么数据或关系、改哪一层、预期检查什么”，不写空泛展望。\par
\noindent\textbf{\color{inkblue}交稿前查：}是否把速度快、精度高、适用面广当成无证据套话；改进是否超出当前数据，是否被误写成现有成果。
\end{quote}
