\subsection{灵敏度或稳健性分析}
\begin{quote}\small
\noindent\textbf{\color{inkblue}写什么：}选择会受测量、估计或情景变化影响的关键参数，观察输出数值与决策是否改变。\par
\noindent\textbf{\color{inkblue}怎么写：}先给基准值、扰动来源和范围；每次写清固定量、改变量和输出。连续结果报变化幅度，离散决策说明何时换方案。\par
\noindent\textbf{\color{inkblue}交稿前查：}是否把求解步长加密误当成灵敏度；不同参数是否用了可比较的扰动尺度；是否只展示最好看的方向。
\end{quote}
