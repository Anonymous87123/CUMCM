\subsection{结果分析与模型检验}
\begin{quote}\small
\noindent\textbf{\color{inkblue}写什么：}报告关键结果，解释方向、数量级、约束状态和现实含义；再用与结论匹配的办法检查。\par
\noindent\textbf{\color{inkblue}怎么写：}表格给精确数值，图形展示关系或状态。正文从一个具体结果起笔，随后解释它由哪个机制或约束造成。回代、守恒、残差、交叉验证、基线对照和反例分别按实际职责命名。\par
\noindent\textbf{\color{inkblue}交稿前查：}是否只复述表中数字；图表是否在正文出现并被解释；“最优、准确、稳定”等判断有没有候选范围、指标和比较对象。
\end{quote}
