\subsection{分问题模型建立与求解}
\begin{quote}\small
\noindent\textbf{\color{inkblue}写什么：}每问给出输入数据、变量、方程或目标、约束、求解步骤、输出和必要图表。\par
\noindent\textbf{\color{inkblue}怎么写：}给出最简单可核的模型，并点明它在哪个可观察情形不足；只对该缺口增加项或更换方法。公式后解释量的含义，算法写清初始化、更新、可行性处理、停止条件和输出文件。\par
\noindent\textbf{\color{inkblue}交稿前查：}是否只有算法名没有数学模型；约束能否追到题意；多根、分段、随机种子、搜索范围和终止精度是否交代；前问接口是否真的可复用。
\end{quote}
