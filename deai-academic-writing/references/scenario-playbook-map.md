# Genre Playbook Scene Map

The original eleven playbooks now route as follows.

| Base playbook | Primary scene | Conditional routing |
|---|---|---|
| 1. Mathematical modeling paper | MOD | A new theoretical theorem inside it borrows RES proof gates locally |
| 2. Algorithm/method paper | RES | A purely operational benchmark/README uses MOD instead |
| 3. Experimental results and robustness report | MOD | Journal contribution framing may use RES for title/abstract only |
| 4. Literature review and paper-to-project note | RES | A classroom reading summary with no synthesis uses NOTE |
| 5. Textbook chapter | NOTE | Original research monograph claims use RES for those claims |
| 6. Examination solution and strategy manual | NOTE | Never route its heuristics into MOD/RES evidence |
| 7. Audit/quality/closure report | MOD | Course-answer audits remain NOTE but keep CORE status gates |
| 8. Engineering README and operation manual | MOD | Research novelty sections are separate RES segments |
| 9. OCR/transcription reconstruction | NOTE | Source text remains `SRC/OCR`, not a style scene |
| 10. Research plan and manuscript blueprint | RES | Experiment protocol tables may borrow MOD gates |
| 11. Product or competition presentation | MOD | Pure marketing material is non-target and must not support academic claims |

## Split rule

If a file contains two playbooks, split it. A 6,000-line README containing a
current manual, historical plans, test report, and defense script does not have
one scene voice. Assign authority and state to each segment before rewriting.
