## Reuse rule

Use the receiving child skill's own rewrite pattern when available. A base
pattern supplies the invariant repair, not final tone. For example, NOTE and
RES may both repair local-to-global reasoning, but NOTE explains the domain
partition for learners while RES states the proof certificate more compactly.
